## १. चल (Variable) म्हणजे काय?

**चल** म्हणजे माहिती **साठवण्यासाठी** दिलेले **नाव**. ज्याप्रमाणे आपण एका डब्यावर "साखर" असे लेबल लावतो आणि त्यात साखर ठेवतो, तसेच चल हे माहितीसाठी एक डबा आहे.

### सिंटॅक्स (Syntax)

```python
चलाचे_नाव = किंमत
```

| भाग | अर्थ |
|---|---|
| `चलाचे_नाव` | आपण निवडलेले नाव |
| `=` | "नेमून दे" (assign) चे चिन्ह — समान नाही! |
| `किंमत` | त्या चलात साठवायची माहिती |

### उदाहरण

```python
naav = "अर्जुन"       # string साठवली
vay = 15              # integer साठवली
unchi = 5.6           # float साठवली
ahe_vidyarthi = True  # boolean साठवली
```

---

## २. चलाच्या नावांचे नियम (Rules for Variable Names)

| ✅ नियम | उदाहरण |
|---|---|
| अक्षरे, अंक व `_` वापरता येतात | `naav`, `vay_1`, `_score` |
| सुरुवात अक्षराने किंवा `_` ने | `nav` ✅, `1nav` ❌ |
| केस-सेन्सिटिव्ह (case-sensitive) | `Nav` व `nav` वेगळे |
| पायथनचे keyword वापरू नये | `if`, `for`, `class` ❌ |
| जागा (space) चालत नाही | `my nav` ❌, `my_nav` ✅ |

## ३. पायथनमधील मुख्य माहिती-प्रकार (Data Types)

| प्रकार | अर्थ | उदाहरण |
|---|---|---|
| `int` | पूर्णांक (Integer) | `25`, `-100`, `0` |
| `float` | दशांश संख्या | `3.14`, `-0.5` |
| `str` | अक्षरमाला (String) | `"राम"`, `'पायथन'` |
| `bool` | खरे/खोटे (Boolean) | `True`, `False` |
| `list` | यादी | `[1, 2, 3]` |
| `tuple` | अपरिवर्तनीय यादी | `(1, 2, 3)` |
| `dict` | शब्दकोश | `{"naav": "राम"}` |
| `set` | वेगवेगळ्या वस्तूंचा संच | `{1, 2, 3}` |
| `NoneType` | "काही नाही" | `None` |

---

## ४. `type()` फंक्शन

कोणत्याही चलाचा प्रकार ओळखण्यासाठी `type()` वापरतात.

```python
vay = 15
print(type(vay))   # <class 'int'>

naav = "राम"
print(type(naav))  # <class 'str'>
```

---

## ५. प्रकार बदलणे (Type Casting)

एका प्रकाराचा डेटा दुसर्‍या प्रकारात बदलण्याला **type casting** म्हणतात.

| फंक्शन | काम |
|---|---|
| `int(x)` | `x` ला integer मध्ये बदलते |
| `float(x)` | `x` ला float मध्ये बदलते |
| `str(x)` | `x` ला string मध्ये बदलते |
| `bool(x)` | `x` ला boolean मध्ये बदलते |

### उदाहरण

```python
sankhya = "25"          # ही string आहे
sankhya_int = int(sankhya)  # आता ती integer झाली
print(sankhya_int + 5)      # 30
```

## 📝 शब्दकोश (Glossary)
