# पायथन प्रोग्रामिंग कोर्स (Python Programming Course)

### महाराष्ट्र राज्य शिक्षण मंडळाच्या विद्यार्थ्यांसाठी — मराठी भाषेत

> **उद्देश:** हा कोर्स महाराष्ट्र राज्य शिक्षण मंडळाच्या (SSC व HSC) विद्यार्थ्यांसाठी संपूर्ण मराठीतून तयार केला आहे. प्रत्येक संकल्पना (concept), सिंटॅक्स (syntax) चे अर्थ, उपयोग, हाताळून पाहण्यासारखे प्रयोग (hands-on labs) आणि प्रत्येक लॅबमध्ये वापरलेले प्रत्येक शब्द (term) यांचे स्पष्टीकरण दिले आहे.

---

## 📚 कोर्सचे स्वरूप (Course Structure)

प्रत्येक प्रकरणात (chapter मध्ये) खालील गोष्टी असतील:

1. **संकल्पना (Concept)** — काय, का व कुठे वापरतात?
2. **सिंटॅक्स (Syntax)** — योग्य लिहिण्याची पद्धत आणि प्रत्येक शब्दाचा अर्थ
3. **उदाहरणे (Examples)** — सोपी, समजण्यासारखी मराठीतील उदाहरणे
4. **हँड्स-ऑन लॅब (Hands-on Lab)** — स्वतः चालवून पाहण्यासारखे प्रोग्राम्स (`.py` फाइल्स)
5. **लॅबमधील प्रत्येक टर्मचे स्पष्टीकरण** — कोणता शब्द काय करतो?
6. **स्वाध्याय (Practice Questions)** — स्वतः सोडवण्यासाठी प्रश्न

## 🎯 हा कोर्स कोणासाठी?

- इयत्ता ९वी, १०वी, ११वी, १२वी (विज्ञान/संगणक शास्त्र) — महाराष्ट्र राज्य मंडळ
- ज्या विद्यार्थ्यांना इंग्रजी फार येत नाही पण कोडिंग शिकायचे आहे
- शिक्षक जे मराठी माध्यमातून पायथन शिकवू इच्छितात
- संपूर्ण नवशिक्या (Absolute Beginners)

## 🛠️ कोर्स कसा वापरावा?

1. **`00_setup/README.md`** पासून सुरुवात करा — पायथन कसे install करायचे ते शिका.
2. प्रत्येक प्रकरणाचा `README.md` आधी वाचा.
3. नंतर त्या प्रकरणातील `lab_*.py` फाइल्स आपल्या संगणकावर चालवून पाहा.
4. लॅबच्या शेवटी दिलेले स्वाध्याय सोडवा.
5. शेवटी `projects/` फोल्डरमधील प्रोजेक्ट्स पूर्ण करा.

### प्रोग्राम कसा चालवायचा?

```bash
python filename.py
```
