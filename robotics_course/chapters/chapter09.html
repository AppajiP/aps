प्रकल्प १७: Light Controlled Machine

Azone Academy • रचना: Appaji Patil • अडचण: ★★☆ मध्यम

१. ध्येय

वातावरणातील उजेड मोजून, अंधार पडताच यंत्र (पंखा / दिवा) स्वतःहून चालू करायचे आणि उजेड येताच बंद. — एक छोटा automatic on/off स्विच.

उपयोग: स्वयंचलित night lamp, दूधाच्या भांड्यावर झाकण उघडल्यावर पंखा/मोटर सुरू, गोदामात light-trigger conveyor.

२. मूळ कल्पना

LDR चा रेझिस्टन्स उजेडाच्या तीव्रतेनुसार बदलतो — अंधारात जास्त (~१ MΩ), उजेडात कमी (~१ kΩ). LDR ला 10 kΩ रेझिस्टरसह व्होल्टेज डिव्हायडर बनवून A0 शी जोडतो. analogRead(A0) ची संख्या एक थ्रेशोल्डपेक्षा कमी झाली = "अंधार" = आउटपुट चालू.

३. साहित्य

  • Arduino UNO
  • LDR + 10 kΩ resistor
  • 5V Relay मॉड्यूल (किंवा NPN ट्रांझिस्टर BC547 + dual ओव्हर रिले)
  • लोड (5V DC fan किंवा LED ‘बल्ब’)
  • ब्रेडबोर्ड + जम्पर वायर्स
सुरक्षा 230V मेन्ससह कधीही प्रयोग करू नका. सरावासाठी 5V DC fan किंवा एक मोठा LED वापरा.

६. Arduino कोड

/* प्रकल्प १७ — Light Controlled Machine
   Azone Academy • Appaji Patil */

const int LDR_PIN   = A0;
const int RELAY_PIN = 7;
const int LED_PIN   = 13;
const int THRESHOLD = 400;   // ह्या खाली = अंधार
const bool DARK_ON  = true;  // true = अंधारात लोड चालू

void setup() {
  pinMode(RELAY_PIN, OUTPUT);
  pinMode(LED_PIN, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int light = analogRead(LDR_PIN);   // 0 – 1023
  Serial.print("उजेड: ");
  Serial.println(light);

  bool dark = (light < THRESHOLD);
  bool turnOn = DARK_ON ? dark : !dark;

  digitalWrite(RELAY_PIN, turnOn ? HIGH : LOW);
  digitalWrite(LED_PIN,   turnOn ? HIGH : LOW);
  delay(200);
}

७. कोडचे विश्लेषण

  • analogRead(A0) — व्होल्टेज डिव्हायडरचे मूल्य ० ते १०२३ मध्ये मिळते. अंधारात कमी, उजेडात जास्त (आपल्या सर्किट प्रमाणे).
  • THRESHOLD — ही सीमा. Serial Monitor मधून आपल्या खोलीचे "अंधार-उजेड" मूल्ये पाहून ती ठरवा.
  • DARK_ON — true = अंधारात चालू (night lamp). false = उजेडात चालू (दिवसा कुलर).
  • delay(200) — दर ०.२ सेकंदाला तपासणी. खूप वारंवार स्विच ऑफ-ऑन होणे टाळते.

१०. अधिक करा

  • दोन थ्रेशोल्ड — चालू ३५० च्या खाली, बंद ५०० च्या वर (हिस्टेरेसिस).
  • PWM ने आपोआप dim/bright — अंधार जास्त = LED अधिक उजळ.
  • Serial Monitor मध्ये दिवस/रात्र मोजणी ठेवा.
