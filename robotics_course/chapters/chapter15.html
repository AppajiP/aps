प्रकल्प २३: Remote Controlled Lamp & Buzzer

Azone Academy • रचना: Appaji Patil • अडचण: ★★☆ मध्यम

१. ध्येय

तुमच्या TV / set-top box च्या रिमोटच्या बटणाने एक दिवा चालू-बंद आणि बझर चालू-बंद करा. हा प्रकल्प पुढच्या प्रकल्पाचा (पंखा गती नियंत्रण) पाया आहे.

२. IR रिमोट कसा चालतो?

टीव्ही रिमोटमधील LED ३८ kHz च्या वारंवारतेने इन्फ्रारेड डाळी (pulses) पाठवते. प्रत्येक बटणाला एक वेगळा code (binary number) नियुक्त असतो. TSOP1738 / VS1838B हा रिसीव्हर ती पल्स पकडतो आणि Arduino ला डिजिटल सिग्नल देतो.

NEC प्रोटोकॉल भारतात बहुतेक रिमोट NEC प्रोटोकॉल वापरतात — प्रत्येक बटणाचा 32-bit हेक्साडेसिमल कोड.

३. IRremote लायब्ररी

Arduino IDE मध्ये Sketch → Include Library → Manage Libraries → IRremote शोधा आणि स्थापित करा (Ken Shirriff ची लायब्ररी).

#include <IRremote.h>
IRrecv ir(2);     // pin 2

void setup() {
  Serial.begin(9600);
  ir.enableIRIn();
}

void loop() {
  if (ir.decode()) {
    Serial.println(ir.decodedIRData.command, HEX);
    ir.resume();
  }
}

हा प्रोग्राम चालवून तुमच्या रिमोटच्या प्रत्येक बटणाचा कोड Serial Monitor मध्ये पाहा. ते कोड पुढच्या कोडमध्ये वापरा.

४. साहित्य

  • Arduino UNO
  • TSOP1738 IR Receiver
  • कोणताही IR remote (TV/set-top box/AC)
  • 5V Relay मॉड्यूल (दिव्यासाठी)
  • 5V Active Buzzer
  • LED bulb / DC bulb (पर्यायी)

६. Arduino कोड

/* प्रकल्प २३ — Remote Controlled Lamp & Buzzer
   Azone Academy • Appaji Patil */

#include <IRremote.h>

const int IR_PIN  = 2;
const int LAMP    = 7;
const int BUZZER  = 8;

// तुमच्या रिमोटच्या कोडसह बदला (Serial वरून पहा)
const uint32_t BTN_1 = 0x45;   // लॅम्प चालू
const uint32_t BTN_2 = 0x46;   // लॅम्प बंद
const uint32_t BTN_3 = 0x47;   // बझर चालू
const uint32_t BTN_4 = 0x44;   // बझर बंद

bool lampOn = false;
bool buzOn  = false;

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN);
  pinMode(LAMP, OUTPUT);
  pinMode(BUZZER, OUTPUT);
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t cmd = IrReceiver.decodedIRData.command;
    Serial.print("कोड: 0x"); Serial.println(cmd, HEX);

    if      (cmd == BTN_1) lampOn = true;
    else if (cmd == BTN_2) lampOn = false;
    else if (cmd == BTN_3) buzOn  = true;
    else if (cmd == BTN_4) buzOn  = false;

    digitalWrite(LAMP,   lampOn ? HIGH : LOW);
    digitalWrite(BUZZER, buzOn  ? HIGH : LOW);

    IrReceiver.resume();
  }
}

८. समस्यानिवारण

  • कोणताच कोड Serial वर येत नाही — TSOP च्या VCC/GND/OUT उलट जोडले असू शकतात (datasheet तपासा).
  • दर वेळी वेगळा कोड येतो — रिमोट "रिपीट" सिग्नल पाठवतो; आपण command फील्डच वापरतो, address नाही.
  • लाँग प्रेस झाला तरी प्रत्येक frame ला toggle — कोडमध्ये previous-state check ठेवा.

९. अधिक करा

  • Power बटण = ‘all toggle’ (दिवा + बझर एकाच क्लिकवर).
  • RGB LED + 3 बटणे = रंग बदल.
  • Mode बटण — समान बटणे वेगवेगळ्या मोडमध्ये वेगळी कामं.
