प्रकल्प १८: Cliff Avoiding Robot

Azone Academy • रचना: Appaji Patil • अडचण: ★★☆ मध्यम

१. ध्येय

एक रोबो ज्याला टेबलवरून किंवा कड्यावरून पडायचे नाही. खाली एक IR sensor बसवू — जोपर्यंत खाली जमीन आहे, IR ची किरण परत येते (अडथळा) → रोबो पुढे चालत राहतो. जागा संपली (कडा) → IR ची किरण कुठेच आदळत नाही → रोबो थांबतो/वळतो.

२. मूळ कल्पना

  • रोबोच्या समोरील भागाला खाली पाहणारा IR Obstacle sensor लावा (4-5 cm उंचीवर).
  • जमीन = अडथळा = OUT पिन LOW.
  • कडा / खाली जागा नाही = OUT पिन HIGH → रोबो थांबा / मागे वळा.
‘Cliff’ म्हणजे? टेबलचा कडा, पायऱ्यांची सुरुवात, गच्चीचा कडा — कोणतीही जागा जिथे पुढे खोली आहे.

३. साहित्य

  • Arduino UNO
  • 2-व्हील रोबो चेसिस (बॅटरी होल्डर सहित)
  • L293D मोटर ड्रायव्हर IC (किंवा L298N मॉड्यूल)
  • IR Obstacle Sensor × १ (खाली पाहणारा)
  • 4 × AA बॅटरी (6V)
  • लाल LED + 220Ω (वार्निंग)

५. सर्किट आकृती

         Arduino                  L293D
       ┌─────────┐             ┌──────────┐
   D3 ─┤EN1      │             │       OUT1├── Left motor +
   D5 ─┤IN1      │   ───────►  │       OUT2├── Left motor -

  D11 ─┤EN2      │             │ VCC2 (6V) ←── बॅटरी
       └─────────┘             └──────────┘

   D2  ←── IR (खाली पाहणारा) OUT

६. Arduino कोड

/* प्रकल्प १८ — Cliff Avoiding Robot
   Azone Academy • Appaji Patil */

const int IR_DOWN = 2;
const int EN1=3, IN1=5, IN2=6;     // डावी मोटर
const int EN2=11, IN3=9, IN4=10;   // उजवी मोटर
const int LED = 13;
const int SPEED = 180;             // 0 – 255

void setup() {
  pinMode(IR_DOWN, INPUT);
  pinMode(LED, OUTPUT);
  int outs[] = {EN1, IN1, IN2, EN2, IN3, IN4};
  for (int p : outs) pinMode(p, OUTPUT);
  analogWrite(EN1, SPEED);
  analogWrite(EN2, SPEED);
  Serial.begin(9600);
}

void forward() {
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}
void stopBot() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, LOW);
}
void backward() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
}
void turnLeft() {
  digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH);
  digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
}

void loop() {
  int cliff = digitalRead(IR_DOWN);

  if (cliff == HIGH) {       // खाली जमीन नाही = कडा!
    digitalWrite(LED, HIGH);
    Serial.println("⚠ कडा!");
    stopBot();      delay(200);
    backward();     delay(500);
    turnLeft();     delay(500);
  } else {
    digitalWrite(LED, LOW);
    forward();
  }
}

७. कोडचे विश्लेषण

  • forward / stopBot / backward / turnLeft — चार लहान फंक्शन्स; पुनःवापर सोपा होतो.
  • analogWrite(EN1, SPEED) — मोटरचा वेग; EN पिन PWM साठी आहे.
  • cliff == HIGH — IR ने अडथळा (जमीन) दिसत नाही म्हणजे कडा.
  • delay() सोबत reverse + turn — कडा पासून दूर हलते.

९. समस्यानिवारण

  • रोबो थांबतच नाही — IR sensor खाली नाही, समोर लागलेला आहे. खाली 4-5 cm वर fix करा.
  • हलक्या/कागदी रंगाच्या टेबलवर खोटे "कडा" — IR ची संवेदनशीलता कमी करा.
  • मोटर्स फिरत नाहीत — बॅटरी कमी असू शकते (4 AA = 6V हवे, ‘used’ नकोत).

१०. अधिक करा

  • २ IR sensors (डावा/उजवा) — कोणत्या बाजूचा कडा आहे ते ओळखून त्या उलट दिशेने वळा.
  • Ultrasonic + Cliff दोन्ही जोडून पूर्ण obstacle avoiding रोबो.
  • Buzzer सहित ‘चेतावणी’ संगीत.
