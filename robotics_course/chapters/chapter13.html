प्रकल्प २१: Advanced Automation — Smart Street Light

Azone Academy • रचना: Appaji Patil • अडचण: ★★★ मध्यम-कठीण

१. ध्येय

रस्त्यावरचे दिवे — दिवसा बंद, रात्री पूर्ण उजेड? — किती वीज वाया जाते! आपण एक स्मार्ट दिवा बनवू: (१) दिवसा बंद, (२) रात्री कुणीही नसताना मंद, (३) रात्री हालचाल झाल्यास पूर्ण उजळ.

२. मूळ कल्पना

  • LDR — दिवस की रात्र ओळखतो.
  • PIR sensor — माणूस/वाहन जवळ आल्यास HIGH.
  • PWM (analogWrite) — LED ची तीव्रता ० / २५ / १००% मध्ये बदलणे.

३. ऊर्जा बचत — का महत्त्वाची?

एका रस्त्यावर साधारणपणे २०० दिवे, प्रत्येक ७० W = एकूण १४ kW. रात्रभर सुरू =

14 kW × 12 तास = 168 kWh प्रत्येक दिवस
                  × ३०      = 5040 kWh दर महिना
                  × ₹८/kWh = ₹४०,३२० वीज बिल

स्मार्ट दिव्यांनी सरासरी ५०% बचत शक्य. ही नुसती पैशांची नाही — कोळसा/कार्बन बचत.

४. साहित्य

  • Arduino UNO
  • LDR + 10 kΩ resistor
  • PIR sensor (HC-SR501)
  • उच्च-शक्तीचा LED (1 W) + 220Ω; किंवा LED स्ट्रिप
  • NPN ट्रांझिस्टर (2N2222) — LED स्ट्रिप साठी

६. Arduino कोड

/* प्रकल्प २१ — Smart Street Light
   Azone Academy • Appaji Patil */

const int LDR = A0;
const int PIR = 2;
const int LED = 9;
const int DARK_THRESHOLD = 400;

void setup() {
  pinMode(PIR, INPUT);
  pinMode(LED, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int light  = analogRead(LDR);
  int motion = digitalRead(PIR);
  bool dark  = light < DARK_THRESHOLD;

  int brightness = 0;
  if (dark && motion == HIGH) brightness = 255;    // पूर्ण उजेड
  else if (dark)               brightness = 60;     // मंद (~25%)
  else                         brightness = 0;      // दिवस

  analogWrite(LED, brightness);

  Serial.print("Light:"); Serial.print(light);
  Serial.print(" PIR:"); Serial.print(motion);
  Serial.print(" PWM:"); Serial.println(brightness);
  delay(100);
}

८. समस्यानिवारण

  • PIR सतत HIGH — सेन्सर "warm-up" साठी पहिल्या ३० सेकंदांचा calibration period लागतो. delay(30000) setup मध्ये जोडा.
  • LED मंद होतच नाही — PWM पिन (3,5,6,9,10,11) वापरला आहे का?
  • दिवसा LED चालू — DARK_THRESHOLD खूप जास्त; तो कमी करा.

९. अधिक करा

  • अनेक दिवे — एकाने हालचाल पकडली तर ३ शेजारच्या दिव्यांना सिग्नल पाठवणे (mesh).
  • दर तासाची वीज वापर मोजून ऊर्जा बचतीचा ग्राफ.
  • Solar panel + battery — पूर्णतः off-grid दिवा.
