१. Arduino म्हणजे काय?

Arduino ही एक मुक्त-स्रोत (Open Source) इलेक्ट्रॉनिक प्रोटोटाइप प्लॅटफॉर्म आहे. एका छोट्या PCB बोर्डवर मायक्रोकंट्रोलर बसवलेला असतो. विद्यार्थी, हौशी आणि उद्योग — सर्व ह्याचा वापर करतात कारण:

  • स्वस्त (₹५०० पासून)
  • शिकायला सोपी भाषा (C/C++ आधारित, पण सरल)
  • हजारो लायब्ररी मोफत
  • USB ने थेट प्रोग्राम अपलोड

२. Arduino UNO ची ओळख

आपण कोर्समध्ये Arduino UNO R3 वापरणार आहोत.

३. Arduino IDE (Integrated Development Environment)

Arduino साठी कोड लिहायचा सॉफ्टवेअर — arduino.cc वरून मोफत डाउनलोड करा. स्थापना नंतर:

  1. Arduino USB ने जोडा.
  2. मेनू: Tools → Board → Arduino UNO.
  3. मेनू: Tools → Port → COM3 (किंवा जो दिसेल).
  4. कोड लिहा → ✓ Verify (कंपाइल) → → Upload.
पर्याय: Online IDE ब्राउझरमध्ये थेट चालणारी Tinkercad Circuits — Arduino + सर्किट दोन्ही ऑनलाइन सिम्युलेट करता येतात.

४. Arduino प्रोग्रामची रचना

प्रत्येक Arduino प्रोग्राम (sketch) मध्ये २ अनिवार्य फंक्शन्स असतात:

void setup() {
  // एकदाच चालते — सुरुवातीला
  pinMode(13, OUTPUT);
}

void loop() {
  // सतत पुनःपुन्हा चालते
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
  • setup() — पिन्स कोणते इनपुट/आउटपुट, सिरीयल सुरू करणे, इ.
  • loop() — मुख्य काम जे रोबोला सतत करायचे आहे.

५. मूलभूत फंक्शन्स

फंक्शनकामउदाहरण

digitalWrite(p, v)पिनला HIGH किंवा LOWdigitalWrite(13, HIGH);

analogWrite(p, v)PWM 0–255analogWrite(5, 128);

Serial.begin(b)सिरीयल कम्युनिकेशन सुरूSerial.begin(9600);
Serial.println(x)मूल्य Serial Monitor वर पाठवाSerial.println(v);

६. Serial Monitor — डीबग करण्याचा मित्र

तुमचा सेन्सर काय मूल्य देतोय हे डोळ्यांनी पाहायचे असेल तर Serial Monitor वापरा.

void setup() {
  Serial.begin(9600);
}
void loop() {
  int v = analogRead(A0);
  Serial.print("LDR मूल्य: ");
  Serial.println(v);
  delay(500);
}

Arduino IDE मध्ये Tools → Serial Monitor (Ctrl + Shift + M) उघडा. ९६०० baud निवडा.

७. पहिला प्रोग्राम: Blink

Arduino च्या प्रत्येक प्रोग्रामरचा Hello World.

// Blink — LED चालू-बंद
// Azone Academy / Appaji Patil

int LED = 13;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  digitalWrite(LED, HIGH);  // चालू
  delay(500);               // ०.५ सेकंद
  digitalWrite(LED, LOW);   // बंद
  delay(500);
}
