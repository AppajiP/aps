प्रकल्प २०: Touch Me Not Robot

Azone Academy • रचना: Appaji Patil • अडचण: ★☆☆ सोपा

१. ध्येय

‘Mimosa pudica’ (लाजाळू) रोपासारखा — कोणीतरी स्पर्श केला की रोबो थोडा मागे जातो आणि बझर वाजवतो. टच सोडला की पुन्हा शांत होतो.

२. मूळ कल्पना

रोबोच्या वरच्या बाजूला एक TTP223 Capacitive Touch sensor लावलेला आहे. स्पर्श झाला की त्याचा OUT पिन HIGH होतो; नाहीतर LOW. ह्या एका पिनवरून आपण रोबोला reverse करतो.

३. साहित्य

  • Arduino UNO
  • २-व्हील रोबो चेसिस + 2 मोटर्स
  • L293D मोटर ड्रायव्हर
  • TTP223 Touch Sensor मॉड्यूल
  • 5V Active Buzzer
  • लाल LED + 220Ω
  • बॅटरी पॅक (6V)

४. पिन कनेक्शन

५. Arduino कोड

/* प्रकल्प २० — Touch Me Not Robot
   Azone Academy • Appaji Patil */

const int TOUCH = 2;
const int BUZ = 8, LED = 9;
const int EN1=3, IN1=5, IN2=6;
const int EN2=12, IN3=10, IN4=11;
const int SPEED = 180;

void backward() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW); digitalWrite(IN4, HIGH);
}
void stopBot() {
  digitalWrite(IN1, LOW); digitalWrite(IN2, LOW);
  digitalWrite(IN3, LOW); digitalWrite(IN4, LOW);
}

void setup() {
  pinMode(TOUCH, INPUT);
  pinMode(BUZ, OUTPUT);  pinMode(LED, OUTPUT);
  int outs[] = {EN1, IN1, IN2, EN2, IN3, IN4};
  for (int p : outs) pinMode(p, OUTPUT);
  analogWrite(EN1, SPEED); analogWrite(EN2, SPEED);
}

void loop() {
  if (digitalRead(TOUCH) == HIGH) {
    // स्पर्श!
    digitalWrite(LED, HIGH);
    tone(BUZ, 1500);
    backward();
    delay(800);
    stopBot();
    delay(300);
    noTone(BUZ);
    digitalWrite(LED, LOW);
  } else {
    stopBot();
  }
}

७. समस्यानिवारण

  • स्पर्श न करताच LED चालू — TTP223 चे जम्पर "A" / "B" मोड तपासा (toggle vs direct).
  • Buzzer आवाजच नाही — Active Buzzer हवा (बारकोडवर ‘+’ चिन्ह असलेला).
  • रोबो मागेच जात नाही — L293D ची VCC2 ला बॅटरी जोडलेली का? IN1/IN2 ची polarity बघा.

८. अधिक करा

  • स्पर्शाने रोबो ९०° वळून पुढे जाऊ देणे (escape behaviour).
  • 3 touch pads — डावा/मध्य/उजवा — कोणत्या बाजूला स्पर्श झाला त्यानुसार वळणे.
  • संगीत वाजवणे (tone() च्या वेगवेगळ्या वारंवारतांनी).
