प्रकल्प १६: Tilt Sensor using Obstacle Sensor

Azone Academy • रचना: Appaji Patil • अडचण: ★☆☆ सोपा

१. ध्येय (Goal)

एक IR Obstacle sensor चा वापर करून आपण Tilt detection (झुकाव ओळख) कशी करायची ते शिकू. सर्किट कलले की sensor समोरील वस्तू अदृश्य होते — आणि आपण LED + Buzzer ने अलार्म वाजवतो.

उपयोग: बँकेच्या तिजोरीचा झुकाव अलार्म, मोटारसायकल कलल्यावर सूचना, घरगुती शोपीस पडण्यापासून सतर्कता.

२. मूळ कल्पना

IR sensor समोरच्या वस्तूकडून परावर्तित प्रकाश ओळखतो. आपण सेन्सरसमोर एक स्थिर भिंत/कार्डबोर्ड ठेवू. जोपर्यंत सेन्सर सरळ आहे — भिंत समोर — आउटपुट LOW. कलले की भिंत कोनातून बाहेर जाते — आउटपुट HIGH. ह्या बदलावरून आपण झुकाव ओळखतो.

हे करण्यासाठी सेन्सरला असे माउंट करा की सरळ स्थितीत त्याच्या समोर ५ – १० cm वर एक भिंत/कोपरा असेल.

३. लागणारे साहित्य

  • Arduino UNO + USB केबल
  • IR Obstacle Sensor × १
  • 5 mm LED (लाल) × १ + 220 Ω resistor
  • 5V Active Buzzer × १
  • ब्रेडबोर्ड + जम्पर वायर्स
  • एक छोटी भिंत (कार्डबोर्ड) IR समोर माउंट करण्यासाठी

६. Arduino कोड

/* प्रकल्प १६ — Tilt Sensor using Obstacle Sensor
   Azone Academy • Appaji Patil */

const int IR_PIN     = 2;
const int LED_PIN    = 8;
const int BUZZER_PIN = 9;

void setup() {
  pinMode(IR_PIN, INPUT);
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  Serial.begin(9600);
  Serial.println("Tilt Alarm तयार...");
}

void loop() {
  int state = digitalRead(IR_PIN);
  // सरळ असताना भिंत दिसते -> LOW
  // कलल्यावर भिंत नाही -> HIGH (झुकाव!)

  if (state == HIGH) {
    digitalWrite(LED_PIN, HIGH);
    tone(BUZZER_PIN, 1000);    // 1 kHz बीप
    Serial.println("⚠ झुकले!");
  } else {
    digitalWrite(LED_PIN, LOW);
    noTone(BUZZER_PIN);
    Serial.println("✓ स्थिर");
  }
  delay(100);
}

७. कोडचे विश्लेषण

ओळस्पष्टीकरण
const int IR_PIN = 2;स्थिर पिन क्रमांक — नंतर बदलल्यास सोपे.
pinMode(IR_PIN, INPUT);IR पिन = इनपुट. सेन्सरचे आउटपुट इथे येते.
digitalRead(IR_PIN)HIGH (1) किंवा LOW (0) मूल्य वाचते.
tone(BUZZER_PIN, 1000);१ kHz वारंवारतेचा बीप वाजवते. noTone() ने थांबवा.
delay(100);१०० ms = सेकंदाला १० वेळा तपासणी (10 Hz polling).
HIGH/LOW उलटे का? IR sensor मध्ये "Active Low" लॉजिक: अडथळा असेल = LOW, मोकळी जागा = HIGH. म्हणून सरळ स्थितीत समोर भिंत असेल → LOW. कलले की भिंत निसटली → HIGH = झुकाव.
