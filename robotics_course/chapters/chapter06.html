१. अ‍ॅक्ट्युएटर म्हणजे काय?

अ‍ॅक्ट्युएटर म्हणजे रोबोचा आउटपुट घटक. प्रोसेसरने ठरवलेला निर्णय भौतिक कृतीत बदलणारे साधन.

उदाहरणे:

  • हालचाल — DC motor, Servo motor, Stepper motor
  • उजेड — LED, बल्ब
  • आवाज — Buzzer, स्पीकर
  • स्विचिंग — Relay (मेन्स ऍप्लायन्ससाठी)

२. LED आणि Buzzer

दोघेही Arduino च्या डिजिटल पिनला डायरेक्ट जोडता येतात — फक्त ⚠ रेझिस्टर लावा!

int LED = 13;
void setup() { pinMode(LED, OUTPUT); }
void loop() {
  digitalWrite(LED, HIGH);  // LED चालू
  delay(500);
  digitalWrite(LED, LOW);   // LED बंद
  delay(500);
}

Buzzer सुद्धा अगदी हाच कोड वापरून बीप-बीप करेल.

३. DC मोटर

DC मोटरला + आणि − व्होल्टेज लावले की ती फिरते. ध्रुव उलटे केले की दुसऱ्या दिशेने फिरते. पण Arduino डायरेक्ट मोटर चालवू शकत नाही — कारण मोटर ला जास्त प्रवाह (~250 mA – 1 A) हवा असतो, तर Arduino च्या पिनला फक्त 20 mA मिळतो.

लक्षात ठेवा Arduino पिनला थेट मोटर लावल्यास Arduino जळतो. मध्ये मोटर ड्रायव्हर लागतो.

दोन DC मोटर्स पुढे/मागे + वेगाने नियंत्रित करण्यासाठी आदर्श IC. १६ पिन्स.

५. PWM — Pulse Width Modulation

मोटरचा वेग बदलण्यासाठी आपण analogWrite(pin, value) वापरतो. value 0 ते 255 दरम्यान असते. ० = बंद, १२७ = अर्धा वेग, २५५ = पूर्ण वेग.

प्रत्यक्षात Arduino पिन HIGH आणि LOW दरम्यान वेगाने स्विच करतो — HIGH चे ‘रुंदी’ बदलून सरासरी व्होल्टेज बदलते. 

analogWrite(5, 0);    // बंद
analogWrite(5, 128);  // ~50% वेग
analogWrite(5, 255);  // पूर्ण वेग

Arduino UNO वर PWM पिन्स: 3, 5, 6, 9, 10, 11 (तरंगिकेच्या ~ चिन्हाने ओळखले जातात).

६. Servo मोटर

0° ते 180° ह्या कोनात अचूक फिरते. ३ तारा: VCC (5V), GND, Signal (PWM).

#include <Servo.h>
Servo myServo;

void setup() { myServo.attach(9); }
void loop() {
  myServo.write(0);    delay(1000);  // 0 अंश
  myServo.write(90);   delay(1000);  // 90 अंश
  myServo.write(180);  delay(1000);  // 180 अंश
}

७. Relay — मेन्स ऍप्लायन्स नियंत्रण

Arduino 5V सिग्नल देऊन Relay च्या आत असलेला विद्युतचुंबक चालू करतो, ज्यामुळे 230V चे स्विच जोडले जाते. मग आपण घरगुती दिवा, पंखा, मोटर — काहीही नियंत्रित करू शकतो.

सुरक्षा 230V सोबत प्रयोग करताना तज्ज्ञ शिक्षकाच्या उपस्थितीतच करा. कोर्समध्ये आपण 5V LED किंवा 5V DC fan ने सिम्युलेट करू.

१०. सारांश

  • अ‍ॅक्ट्युएटर — रोबोचे आउटपुट साधन (हालचाल, उजेड, आवाज).
