प्रकल्प १९: Line Follower Robot

Azone Academy • रचना: Appaji Patil • अडचण: ★★★ मध्यम-कठीण

१. ध्येय

एका पांढऱ्या फरशीवर काळ्या टेपची रेषा काढा. रोबो ती रेषा स्वतःहून ओळखून त्यावरून सरळ चालेल — हा "रोबोटिक्सचा Hello World" आहे आणि बहुतेक स्पर्धांचा (Robowars, TechFest) पहिला event असतो.

२. मूळ कल्पना

रोबोच्या तळाला (खाली) दोन IR sensors — डावा आणि उजवा. काळी टेप IR शोषून घेते (no reflection = HIGH); पांढरी फरशी परावर्तन करते (LOW).

दोन्ही सेन्सर्स पांढऱ्यावर असतील = रोबो रेषेच्या मध्यभागी = सरळ चाला. एक सेन्सर काळ्यावर पडला = त्या बाजूला रोबो भरकटला = त्या बाजूला वळा.

३. तर्क-तक्ता (Truth Table)

डावा IRउजवा IRस्थितीकृती
0 (पांढरे)0 (पांढरे)रेषेच्या मध्यभागीदोन्ही मोटर पुढे — सरळ

1 (काळे)1 (काळे)क्रॉसिंग / लाइन संपलीथांब (किंवा सरळ ठेव)

४. साहित्य

  • Arduino UNO
  • २-व्हील रोबो चेसिस + 2 BO गिअर मोटर्स
  • L293D मोटर ड्रायव्हर IC
  • IR Obstacle/Line sensor × २
  • 4 × AA बॅटरी पॅक (6V)
  • काळी इलेक्ट्रिकल टेप (२० mm रुंदी) — पांढऱ्या ट्रॅकसाठी

७. Arduino कोड

/* प्रकल्प १९ — Line Follower Robot
   Azone Academy • Appaji Patil */

const int LEFT_IR  = 2;
const int RIGHT_IR = 4;
const int EN1 = 3, IN1 = 5, IN2 = 6;     // डावी मोटर
const int EN2 = 11, IN3 = 9, IN4 = 10;   // उजवी मोटर
const int SPEED = 170;

void setMotors(int l1, int l2, int r1, int r2) {
  digitalWrite(IN1, l1); digitalWrite(IN2, l2);
  digitalWrite(IN3, r1); digitalWrite(IN4, r2);
}

void setup() {
  pinMode(LEFT_IR, INPUT); pinMode(RIGHT_IR, INPUT);
  int outs[] = {EN1, IN1, IN2, EN2, IN3, IN4};
  for (int p : outs) pinMode(p, OUTPUT);
  analogWrite(EN1, SPEED);
  analogWrite(EN2, SPEED);
  Serial.begin(9600);
}

void loop() {
  int L = digitalRead(LEFT_IR);   // 1 = काळ्यावर
  int R = digitalRead(RIGHT_IR);

  if (L == 0 && R == 0) {              // सरळ
    setMotors(HIGH, LOW, HIGH, LOW);
    Serial.println("↑ सरळ");
  } else if (L == 1 && R == 0) {       // डावीकडे वळ
    setMotors(LOW, LOW, HIGH, LOW);
    Serial.println("← डावीकडे");
  } else if (L == 0 && R == 1) {       // उजवीकडे वळ
    setMotors(HIGH, LOW, LOW, LOW);
    Serial.println("→ उजवीकडे");
  } else {                              // क्रॉसिंग / दोन्ही काळे
    setMotors(LOW, LOW, LOW, LOW);
    Serial.println("⏹ थांब");
  }
}

९. समस्यानिवारण

  • रोबो रेषा सोडतो — दोन सेन्सर्समधले अंतर रेषेच्या रुंदीइतकेच ठेवा.
  • थोडासाच वळ हवा पण रोबो पूर्ण फिरतो — मोटर वेग कमी करा (SPEED 120 करा).
  • एक मोटर वेगवान — मोटर्सच्या वेगांत स्वाभाविक फरक. कोडमध्ये दोन वेगळे SPEED वापरा.

१०. अधिक करा

  • PID controller — गुळगुळीत वळण, उच्च गती; तीन analog IR sensors वापरून.
  • ५ sensor array — खूप अचूक follow.
  • Maze runner — डाव्या-उजव्या क्रॉसवर निर्णय घेणे (left-hand rule).
