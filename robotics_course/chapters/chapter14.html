प्रकल्प २२: Light Seeking Robot

Azone Academy • रचना: Appaji Patil • अडचण: ★★★ मध्यम-कठीण

१. ध्येय

एक रोबो जो टॉर्च/सूर्यप्रकाशाच्या दिशेने स्वतःहून जातो — सूर्यफुलासारखा. ह्याला Photo-tropism असे म्हणतात (वनस्पतीशास्त्र).

२. मूळ कल्पना

दोन LDR — डावी आणि उजवी — रोबोच्या समोरील भागाला थोड्या कोनात लावलेले.

  • दोन्ही LDR सारखे = सरळ.
  • डाव्या LDR वर जास्त उजेड = प्रकाश डावीकडे आहे → डावीकडे वळ.
  • उजव्या LDR वर जास्त उजेड = उजवीकडे वळ.
if (leftLDR > rightLDR + tol)        turnLeft();
else if (rightLDR > leftLDR + tol)    turnRight();
else                                   forward();

३. जैविक प्रेरणा

सूर्यफूल (Sunflower) दिवसभर सूर्याच्या दिशेने आपले डोके फिरवते. ह्या साध्या रोबोमध्ये आपण ती कल्पना यांत्रिक पद्धतीने उतरवली आहे. हे रोबोटिक्समधील biomimicry चे उदाहरण.

४. साहित्य

  • Arduino UNO
  • २-व्हील चेसिस + 2 मोटर्स + L293D
  • २ × LDR + प्रत्येकी 10 kΩ resistor
  • बॅटरी पॅक (6V)
  • एक टॉर्च — चाचणीसाठी 🔦

६. Arduino कोड

/* प्रकल्प २२ — Light Seeking Robot
   Azone Academy • Appaji Patil */

const int L_LDR = A0;
const int R_LDR = A1;
const int EN1=3, IN1=5, IN2=6;
const int EN2=11, IN3=9, IN4=10;
const int SPEED = 160;
const int TOL = 50;     // सहनशीलता

void setMotors(int l1,int l2,int r1,int r2) {
  digitalWrite(IN1,l1); digitalWrite(IN2,l2);
  digitalWrite(IN3,r1); digitalWrite(IN4,r2);
}

void setup() {
  int outs[] = {EN1, IN1, IN2, EN2, IN3, IN4};
  for (int p : outs) pinMode(p, OUTPUT);
  analogWrite(EN1, SPEED); analogWrite(EN2, SPEED);
  Serial.begin(9600);
}

void loop() {
  int L = analogRead(L_LDR);
  int R = analogRead(R_LDR);
  int diff = L - R;

  if (abs(diff) < TOL) {
    setMotors(HIGH, LOW, HIGH, LOW);          // सरळ
    Serial.println("↑ सरळ");
  } else if (L > R) {                          // प्रकाश डावीकडे
    setMotors(LOW, LOW, HIGH, LOW);            // डावीकडे वळ
    Serial.println("← डावीकडे");
  } else {
    setMotors(HIGH, LOW, LOW, LOW);            // उजवीकडे
    Serial.println("→ उजवीकडे");
  }
  delay(80);
}

८. समस्यानिवारण

  • रोबो सतत डाव्या-उजव्या मारतोय — TOL वाढवा (५० → १००).
  • एका LDR मध्ये भलताच आकडा — व्होल्टेज डिव्हायडर तपासा.
  • खोली खूप उजेडात — दोघांचे मूल्य उच्च होते, फरक कमी होतो → कमी प्रकाशात चाचणी करा.

९. अधिक करा

  • Calibration — सुरुवातीच्या ३ सेकंदात दोन्ही LDR ची सरासरी काढून, ती बेसलाइन.
  • ३ किंवा ४ LDR — ३६०° प्रकाश शोध.
  • Light avoiding mode — असमान asymetric इन्व्हर्स लॉजिक (वंदी रोबो जो उजेडापासून पळतो).
