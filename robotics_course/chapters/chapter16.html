प्रकल्प २४: Remote Controlled Fan

Azone Academy • रचना: Appaji Patil • अडचण: ★★★ मध्यम-कठीण

१. ध्येय

रिमोटच्या बटणाने 5V/12V DC पंख्याचा वेग बदलणे — OFF / SLOW / MEDIUM / FAST — PWM वापरून. ह्या अभ्यासक्रमातला हा शेवटचा अधिकृत प्रकल्प आहे, आणि सर्व मागील संकल्पनांचा संगम आहे.

२. कार्यतत्त्व

IR remote कडून मिळणाऱ्या प्रत्येक बटणासाठी आपण एक PWM मूल्य ठरवतो आणि analogWrite() ने मोटरला देतो. मोटर ड्रायव्हर (L293D किंवा NPN ट्रांझिस्टर) तो PWM मोटरच्या पुरवठ्यापर्यंत वाढवतो.

३. गती-तक्ता

बटणस्थितीanalogWrite मूल्य
OFF (0 / Power)बंद0
1मंद80 (~30%)
2मध्यम170 (~65%)
3जलद255 (पूर्ण)

४. साहित्य

  • Arduino UNO
  • TSOP1738 IR Receiver + IR रिमोट
  • 5V – 12V DC पंखा / मोटर
  • L293D (किंवा NPN ट्रांझिस्टर + Diode)
  • 9V बॅटरी पंख्यासाठी

५. पिन कनेक्शन

घटकपिनArduino
TSOP1738OUTD2
L293DIN1 / IN2D7 / D8
L293DEN1 (PWM)D9
L293DVCC2 (पंखा पुरवठा)9V बॅटरी

६. Arduino कोड

/* प्रकल्प २४ — Remote Controlled Fan
   Azone Academy • Appaji Patil */

#include <IRremote.h>

const int IR_PIN = 2;
const int IN1 = 7, IN2 = 8, EN = 9;

const uint32_t BTN_0 = 0x16;   // OFF
const uint32_t BTN_1 = 0x0C;   // SLOW
const uint32_t BTN_2 = 0x18;   // MEDIUM
const uint32_t BTN_3 = 0x5E;   // FAST

int speed = 0;

void setup() {
  Serial.begin(9600);
  IrReceiver.begin(IR_PIN);
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT); pinMode(EN, OUTPUT);
  digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);  // एका दिशेने
}

void loop() {
  if (IrReceiver.decode()) {
    uint32_t c = IrReceiver.decodedIRData.command;
    Serial.print("कोड: 0x"); Serial.println(c, HEX);
    if      (c == BTN_0) speed = 0;
    else if (c == BTN_1) speed = 80;
    else if (c == BTN_2) speed = 170;
    else if (c == BTN_3) speed = 255;
    analogWrite(EN, speed);
    Serial.print("नवीन गती: "); Serial.println(speed);
    IrReceiver.resume();
  }
}

८. समस्यानिवारण

  • पंखा फक्त चालू/बंदच होतो — EN पिन PWM पिनला (D3/5/6/9/10/11) जोडले आहे का?
  • मंद गतीवर पंखा सुरूच होत नाही — DC मोटरला प्रत्येकीचा ‘start torque’ असतो; PWM ८० ऐवजी १००-१२० करा.
  • Arduino रिसेट होतो — पंखा आणि Arduino एकाच बॅटरीवर असू नये; वेगळी बॅटरी द्या.

९. अधिक करा

  • Up/Down बटणाने सतत गती वाढ/कमी (continuous PWM).
  • तापमान सेन्सर (LM35) + ऑटो मोड — खोलीचे तापमान वाढले की गती वाढव.
  • OLED display वर सध्याची गती दाखव.
  • Blynk / Wi-Fi (ESP8266) ने मोबाईल अ‍ॅपवरून पंखा.
