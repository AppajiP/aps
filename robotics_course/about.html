Azone Academy

Azone Academy ही महाराष्ट्रातील विद्यार्थ्यांसाठी STEM (विज्ञान, तंत्रज्ञान, अभियांत्रिकी, गणित) शिक्षण सोप्या मराठीत उपलब्ध करून देणारी संस्था आहे. आमचा उद्देश — “प्रत्येक विद्यार्थ्याला तंत्रज्ञानाचा निर्माता बनवणे.”

आमचे इतर अभ्यासक्रम:

  • Python प्रोग्रामिंग (मराठी)
  • कृत्रिम बुद्धिमत्ता — AI (मराठी)
  • रोबोटिक्स (मराठी) — हा अभ्यासक्रम
AP

Appaji Patil

अभ्यासक्रम रचनाकार आणि वरिष्ठ प्रशिक्षक. इलेक्ट्रॉनिक्स, Arduino व रोबोटिक्स या क्षेत्रांत महाराष्ट्र राज्य मंडळातील विद्यार्थ्यांना हाताने करून शिकवण्याचा अनेक वर्षांचा अनुभव.

ब्रीदवाक्य — “शिकणे म्हणजे हाताने करणे.” म्हणून प्रत्येक धड्यात कोड, सर्किट आकृती, सिम्युलेशन आणि स्वाध्यायचा समावेश आहे.

हा अभ्यासक्रम कोणासाठी?

८ वी ते १२ वी विद्यार्थी

गणित-विज्ञानाची मूलतत्त्वे माहीत असलेले विद्यार्थी सहज शिकू शकतात. इयत्ता ९ - १० पासून सर्वोत्तम अनुभव.

शाळेतील STEM शिक्षक

शिक्षक हा अभ्यासक्रम वर्गात किंवा रोबोटिक्स क्लबसाठी थेट वापरू शकतात — सर्व साधन एका जागी.

पालक

मुलांना डिजिटल कौशल्य शिकवायचे आहे पण इंग्रजीचा अडसर वाटतो? — मराठीतून सहज पर्याय.

स्वयं-शिकणारे

रोबोटिक्सच्या जगात पाऊल टाकू पाहणारा कोणीही — कोणतीही पूर्व-अनुभव नसताना सुरुवात करू शकतो.

तंत्रज्ञान

  • हा अभ्यासक्रम पूर्णतः HTML + CSS + JavaScript मध्ये बनवलेला आहे.
  • कोणताही सर्वर लागत नाही — फक्त index.html ब्राउझरमध्ये उघडा.
  • प्रकल्प सिम्युलेशन्स ब्राउझरमध्येच चालतात — कोणतीही स्थापना (installation) नाही.
  • तुमची प्रगती तुमच्या ब्राउझरच्या localStorage मध्ये साठते.
