- `input()` फंक्शनचा वापर
- वापरकर्त्याकडून संख्या घेणे
- `print()` मध्ये format करणे (f-strings, `.format()`, `%`)

---

## १. `input()` फंक्शन

`input()` हे एक built-in फंक्शन आहे जे **वापरकर्त्याकडून (user) माहिती** घेते. ती माहिती **नेहमी string** स्वरूपात असते.

### सिंटॅक्स

```python
chal = input("दाखवायचा संदेश: ")
```

| भाग | अर्थ |
|---|---|
| `input` | फंक्शनचे नाव |
| `"..."` | वापरकर्त्याला दाखवायचा संदेश (prompt) |
| `chal` | टाइप केलेली माहिती साठवायचे चल |

### उदाहरण

```python
naav = input("तुझे नाव सांग: ")
print("नमस्कार,", naav)
```

---

## २. संख्या घेणे

`input()` नेहमी **string** देते. म्हणून संख्या हवी असेल तर `int()` किंवा `float()` ने बदलावे लागते.

```python
vay = int(input("वय: "))      # integer मध्ये बदलले
unchi = float(input("उंची: "))  # float मध्ये बदलले
```

---

## ३. आउटपुट format करणे

### अ. f-string (सर्वात सोपी पद्धत — Python 3.6+)

```python
naav = "राम"
vay = 15
print(f"माझे नाव {naav} व वय {vay} आहे.")
```

`f` लावल्यानंतर `{ }` मध्ये कोणतेही चल किंवा expression टाकता येते.

### आ. `.format()` पद्धत

```python
print("माझे नाव {} व वय {}".format(naav, vay))
print("माझे नाव {0} व वय {1}".format(naav, vay))
print("माझे नाव {n} व वय {v}".format(n=naav, v=vay))
```

### इ. `%` पद्धत (जुनी पद्धत)

```python
print("नाव: %s, वय: %d" % (naav, vay))
```

| code | अर्थ |
|---|---|
| `%s` | string |
| `%d` | integer |
| `%f` | float |
| `%.2f` | दोन दशांश |

### ई. दशांश मर्यादा (Decimal Places)

```python
pi = 3.141592
print(f"{pi:.2f}")  # 3.14 (२ दशांश)
print(f"{pi:.4f}")  # 3.1416
```
