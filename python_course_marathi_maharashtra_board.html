4) Topic-wise Hands-on Labs

Lab 1: परिचय कार्यक्रम

Topic: print(), input(), comments

name = input("तुमचे नाव टाका: ")
std = input("इयत्ता टाका: ")
school = input("शाळेचे नाव टाका: ")

print("नाव:", name)
print("इयत्ता:", std)
print("शाळा:", school)

Terms:

  • Interpreter: Python code चालवणारे साधन
  • Statement: कोडमधील एक सूचना
  • Prompt: input() मधील प्रश्न मजकूर

Lab 2: गुणपत्रिका

Topic: Variables, data types, conversion

name = input("नाव: ")
m1 = int(input("गणित गुण: "))
m2 = int(input("विज्ञान गुण: "))
m3 = int(input("इंग्रजी गुण: "))

total = m1 + m2 + m3
avg = total / 3
print(name, "एकूण:", total, "सरासरी:", avg)

Terms:

  • Variable: value ठेवण्याची जागा
  • Data Type: int, float, str
  • Type Conversion: प्रकार बदलणे

Lab 3: Calculator

Topic: Operators

a = float(input("पहिली संख्या: "))
b = float(input("दुसरी संख्या: "))
print("बेरीज:", a + b)
print("वजाबाकी:", a - b)
print("गुणाकार:", a * b)
print("भागाकार:", a / b)

Terms:

  • Operand: operator भोवती असलेल्या values
  • Modulo: उरलेली बाकी (%)

Lab 4: Grade Finder

Topic: if-elif-else

marks = int(input("गुण टाका: "))
if marks >= 75:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 35:
    print("Grade C")
else:
    print("नापास")

Terms:

  • Condition: True/False देणारी अट
  • Branching: अटीवरून मार्ग बदलणे

Lab 5: पाढा Program

Topic: Loops

n = int(input("पाढा कोणता?: "))
for i in range(1, 11):
    print(n, "x", i, "=", n * i)

Terms:

  • Iteration: loop ची प्रत्येक फेरी
  • Counter: मोजणी variable

Lab 6: String विश्लेषण

Topic: Strings

text = input("वाक्य टाका: ")
print("लांबी:", len(text))
print("Upper:", text.upper())
print("Lower:", text.lower())
print("पहिली 5 अक्षरे:", text[:5])

Terms:

  • Index: स्थान क्रमांक
  • Slice: मजकूराचा भाग

Lab 7: Dictionary Student Record

Topic: Data structures

student = {}
student["name"] = input("नाव: ")
student["roll"] = int(input("रोल: "))
student["marks"] = int(input("गुण: "))
print(student)

Terms:

  • Key-Value: dictionary नोंद
  • Mutable: बदलता येणारा डेटा प्रकार

Lab 8: Function वापर

Topic: Functions

def percentage(total, out_of):
    return (total / out_of) * 100

total = int(input("एकूण गुण: "))
out_of = int(input("पूर्ण गुण: "))
print("टक्केवारी:", percentage(total, out_of))

Terms:

  • Parameter: function define करताना input नाव
  • Argument: function call मध्ये दिलेली value
  • Return: function कडून आलेला निकाल

Lab 9: File Attendance

Topic: File handling

name = input("नाव: ")
status = input("Present/Absent: ")
with open("attendance.txt", "a", encoding="utf-8") as f:
    f.write(name + " - " + status + "\n")
print("नोंद पूर्ण")

Terms:

  • Append: फाईलच्या शेवटी भर घालणे
  • Encoding: अक्षरांचे साठवण स्वरूप

Lab 10: Error-safe Division

Topic: Exception handling

try:
    a = int(input("संख्या 1: "))
    b = int(input("संख्या 2: "))
    print("भागाकार:", a / b)
except ValueError:
    print("वैध संख्या टाका.")
except ZeroDivisionError:
    print("0 ने भागाकार होत नाही.")
finally:
    print("प्रक्रिया पूर्ण.")

Terms:

  • Exception: रनटाइम त्रुटी
  • ZeroDivisionError: 0 ने भागाकार त्रुटी

Lab 11: OOP Student Class

Topic: Class आणि object

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

    def show(self):
        print(self.name, self.marks)

s1 = Student("Rutuja", 87)
s1.show()

Terms:

  • Class: object तयार करण्याचा साचा
  • Object: class चे instance
  • Attribute: object मधील data

Lab 12: Random Guess

Topic: Modules

from random import randint
num = randint(1, 10)
guess = int(input("1 ते 10 अंदाज: "))
if guess == num:
    print("बरोबर!")
else:
    print("चुकले. योग्य:", num)

Terms:

  • Module: वेगळा Python code file
  • Import: module program मध्ये वापरणे

5) Projects with Practical Hands-on Labs

Project 1: विद्यार्थी गुणपत्रिका व्यवस्थापन प्रणाली

उद्देश: नाव + 5 विषयांचे गुण घेऊन total, average, percentage, grade काढणे.

Practical Steps

  1. input() वापरून नाव व 5 विषयांचे गुण घ्या
  2. गुण list मध्ये साठवा
  3. sum() वापरून total काढा
  4. def function करून percentage काढा
  5. if-elif-else ने grade ठरवा
  6. निकाल report.txt मध्ये save करा

Terms

  • Validation: input योग्य आहे का तपासणे
  • Business Logic: grade/percentage नियम
  • Reusable Function: पुन्हा वापरता येणारे function

Project 2: शाळा ग्रंथालय व्यवस्थापन (Mini LMS)

उद्देश: पुस्तक add, issue, return आणि उपलब्धता ट्रॅक करणे.

Practical Steps

  1. dict मध्ये पुस्तक नाव आणि प्रती संख्या ठेवा
  2. while True menu-driven loop तयार करा
  3. Issue वेळी count कमी करा
  4. Return वेळी count वाढवा
  5. Final record file मध्ये write करा

Terms

  • Menu-driven Program: पर्याय निवडून चालणारा program
  • State: program ची current स्थिती
  • Persistence: data file मध्ये कायम ठेवणे

Project 3: कुटुंब खर्च ट्रॅकर

उद्देश: रोजचा खर्च category नुसार साठवून monthly report बनवणे.

Practical Steps

  1. Category व amount input घ्या
  2. Data list/dictionary मध्ये साठवा
  3. Loop वापरून category-wise totals काढा
  4. सर्वाधिक खर्च असलेली category शोधा
  5. Report expense_report.txt मध्ये save करा

Terms

  • Category: खर्चाचा प्रकार
  • Aggregation: समान data एकत्र करून total काढणे
  • Report: विश्लेषित अंतिम निष्कर्ष
