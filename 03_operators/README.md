# प्रकरण ०३ — ऑपरेटर्स (Operators / क्रियाचिन्हे)

## 🎯 शिकण्याची उद्दिष्टे

- ऑपरेटर्स म्हणजे काय व त्यांचे प्रकार
- अंकगणितीय (Arithmetic) ऑपरेटर्स
- तुलना (Comparison / Relational) ऑपरेटर्स
- तार्किक (Logical) ऑपरेटर्स
- नियुक्तीचे (Assignment) ऑपरेटर्स
- ओळख (Identity) व सदस्य (Membership) ऑपरेटर्स

---

## ऑपरेटर म्हणजे काय?

**ऑपरेटर** म्हणजे असे चिन्ह जे एखादी **क्रिया** करते. जसे गणितात `+`, `-`, `×`, `÷`. पायथनमध्ये अनेक प्रकारचे ऑपरेटर्स आहेत.

---

## १. अंकगणितीय ऑपरेटर्स (Arithmetic)

| ऑपरेटर | अर्थ | उदाहरण | निकाल |
|---|---|---|---|
| `+` | बेरीज | `10 + 3` | `13` |
| `-` | वजाबाकी | `10 - 3` | `7` |
| `*` | गुणाकार | `10 * 3` | `30` |
| `/` | भागाकार (दशांश) | `10 / 3` | `3.333...` |
| `//` | पूर्णांक भागाकार | `10 // 3` | `3` |
| `%` | भाग देऊन शिल्लक | `10 % 3` | `1` |
| `**` | घातांक (power) | `2 ** 3` | `8` |

---

## २. तुलना ऑपरेटर्स (Comparison)

निकाल नेहमी **`True` किंवा `False`** असतो.

| ऑपरेटर | अर्थ | उदाहरण |
|---|---|---|
| `==` | समान आहे का? | `5 == 5` → `True` |
| `!=` | समान नाही का? | `5 != 3` → `True` |
| `>` | मोठे? | `5 > 3` → `True` |
| `<` | छोटे? | `5 < 3` → `False` |
| `>=` | मोठे किंवा समान? | `5 >= 5` → `True` |
| `<=` | छोटे किंवा समान? | `5 <= 3` → `False` |

⚠️ **लक्षात ठेवा:** `=` म्हणजे assignment, `==` म्हणजे तुलना!

---

## ३. तार्किक ऑपरेटर्स (Logical)

| ऑपरेटर | अर्थ |
|---|---|
| `and` | दोन्ही खरी असतील तरच `True` |
| `or` | एक तरी खरी असली तर `True` |
| `not` | उलट करते (`True` → `False`) |

### उदाहरण

```python
vay = 17
print(vay > 14 and vay < 18)  # True (दोन्ही खरे)
print(vay > 18 or vay < 14)   # False (दोन्ही खोटे)
print(not (vay > 18))         # True (खोट्याला उलटवले)
```

---

## ४. नियुक्ती ऑपरेटर्स (Assignment)

| ऑपरेटर | अर्थ | सारखे आहे |
|---|---|---|
| `=` | किंमत द्या | — |
| `+=` | मिळवून पुन्हा साठव | `x = x + 5` |
| `-=` | वजा करून साठव | `x = x - 5` |
| `*=` | गुणून साठव | `x = x * 5` |
| `/=` | भागून साठव | `x = x / 5` |
| `//=` | पूर्णांक भागून | `x = x // 5` |
| `%=` | शिल्लक साठव | `x = x % 5` |
| `**=` | घात देऊन | `x = x ** 2` |

---

## ५. सदस्य ऑपरेटर्स (Membership)

| ऑपरेटर | अर्थ |
|---|---|
| `in` | आत आहे का? |
| `not in` | आत नाही का? |

```python
phale = ["आंबा", "केळी", "सफरचंद"]
print("आंबा" in phale)       # True
print("द्राक्ष" not in phale) # True
```

---

## ६. ओळख ऑपरेटर्स (Identity)

| ऑपरेटर | अर्थ |
|---|---|
| `is` | एकाच ठिकाणी आहेत का? |
| `is not` | एकाच ठिकाणी नाहीत का? |

```python
a = None
print(a is None)  # True
```
