Reading the diagram

  • Centre: the nucleus contains protons (+) and neutrons (0).
  • Rings: each ring is an electron shell K, L, M, N… holding at most 2n² electrons.
  • Atomic number Z = number of protons.
  • Mass number A = protons + neutrons.
  • Neutral atom: electrons = protons. If they differ, the species is an ion.

Filling rule used here

For the first 20 elements the shells fill in the simple sequence 2 → 8 → 8 → 2. This breaks down for transition metals.
