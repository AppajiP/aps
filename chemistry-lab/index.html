About this lab

The pattern of this site is inspired by classroom virtual-experiment libraries: a searchable gallery of cards on the home page, and a dedicated stage with controls, observations, and follow-up questions for each experiment.

All simulations are written from scratch in vanilla JavaScript using the HTML <canvas> and SVG elements. You can open any .html file directly in a modern browser — no build step or server is needed.
