## तंत्रज्ञान

- **HTML5 + CSS3** (कोणतेही build / dependency नाही — फक्त browser मध्ये उघडा).
- **MathJax 3** (CDN) — गणितीय चिन्हे सुंदर रेंडर होण्यासाठी.
- **Google Fonts** — Noto Sans Devanagari, Tiro Devanagari Marathi, Poppins.
- **GeoGebra `iframe` embeds** — तीन प्रयोगशाळा थेट page मध्ये.
- **Vanilla JS** — TOC active highlight, reading progress bar, theme toggle (Dark / Light),
  search filter, "उत्तर पहा" reveal toggle.

## कसा वापरावा

1. कोणत्याही आधुनिक browser मध्ये `index.html` उघडा (Chrome / Firefox / Edge / Safari).
2. किंवा थेट `chapter1_sanch.html` उघडा.
3. प्रत्येक प्रयोगशाळा सरळ embed आहे — fullscreen बटण वापरून मोठ्या स्क्रीनवर पाहता येते.
4. प्रत्येक सरावसंच / समस्यासंच प्रश्नापुढील **"उत्तर पहा"** बटण क्लिक करून उकल पहा.
5. वरील-उजवीकडील theme बटण वापरून Dark / Light mode बदलता येते.
