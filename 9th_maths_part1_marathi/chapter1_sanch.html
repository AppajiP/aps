धडा १ : संच (Sets)

महाराष्ट्र राज्य पाठ्यपुस्तक मंडळ — इयत्ता ९वी · गणित भाग १

या ऑनलाइन वर्गामध्ये आपण संच (Sets) ही संकल्पना अगदी पायाभूत स्तरापासून सुरूवात करून, संचाचे प्रकार, उपसंच, विश्वसंच, संचाच्या क्रिया (युनियन, इंटरसेक्शन, पूरक) आणि n(A∪B) = n(A) + n(B) − n(A∩B) या महत्त्वाच्या सूत्रापर्यंत प्रवास करणार आहोत. प्रत्येक टप्प्यावर GeoGebra प्रयोगशाळा, सोडवलेली उदाहरणे (टप्प्या-टप्प्याने उकल) आणि सरावसंच व समस्यासंच यांची संपूर्ण उत्तरे दिली आहेत.

घटक १.१

संच — संकल्पना व ओळख

आपल्या आजूबाजूला आपण अनेक "गटांविषयी" बोलतो — आपल्या वर्गातील विद्यार्थ्यांचा गट, खेळातील खेळाडूंचा संघ, रंगांचा संग्रह, इत्यादी. गणितात अशा निश्चित (well-defined), वेगवेगळ्या वस्तूंच्या एकत्रित संग्रहाला संच (Set) असे म्हणतात.

व्याख्या
संच म्हणजे निश्चित (well-defined) व परस्पर भिन्न वस्तूंचा संग्रह. संचातील प्रत्येक वस्तूला त्या संचाचा घटक (element) म्हणतात. संच नेहमी इंग्रजी भांडवली अक्षरांनी (A, B, C, ...) दर्शवतात आणि घटक छोट्या अक्षरांनी (a, b, c, ...) किंवा अंकांनी दर्शवतात.

संच की संग्रह?

कोणताही संग्रह संच असू शकत नाही. तो "निश्चित" असला पाहिजे.

संग्रहसंच आहे का?कारण
इंद्रधनुष्यातील रंग✅ होतंबाकू / सात रंग निश्चित आहेत.
वर्गातील उंच विद्यार्थी❌ नाही"उंच" ही व्याख्या व्यक्तिनिष्ठ आहे.
गावातील श्रीमंत लोक❌ नाही"श्रीमंत" स्पष्ट निकष नाही.
१ ते १० मधील सम संख्या✅ होसंख्या स्पष्ट व निश्चित.

घटक दर्शवण्याचे चिन्ह

  • जर x हा संच A चा घटक असेल, तर लिहिले जाते : $x \in A$ (वाचा : "x हा A चा घटक आहे").
  • जर x हा संच A चा घटक नसेल, तर लिहिले जाते : $x \notin A$.
सूचना
संचातील घटक परस्पर भिन्न असतात. म्हणून A = {१, २, २, ३} हे चुकीचे आहे. त्याऐवजी A = {१, २, ३} असे लिहावे. तसेच, संचातील घटकांच्या क्रमाला महत्त्व नसते; म्हणजेच {१, २, ३} = {३, १, २}.

परिचित संच (पाठांतर करण्यासारखे)

  • $N$ = नैसर्गिक संख्यांचा संच = {१, २, ३, ४, ...}
  • $W$ = पूर्ण संख्यांचा संच = {०, १, २, ३, ...}
  • $I$ किंवा $\mathbb{Z}$ = पूर्णांकांचा संच = {..., −३, −२, −१, ०, १, २, ३, ...}
  • $Q$ = परिमेय संख्यांचा संच = $\{ \tfrac{p}{q} \,|\, p, q \in I,\ q \neq 0 \}$
  • $R$ = वास्तव संख्यांचा संच
घटक १.२

संच लिहिण्याच्या पद्धती

संच दर्शविण्याच्या मुख्य दोन पद्धती आहेत :

1

यादी पद्धत (Roster / Listing Method)

संचातील सर्व घटक स्वल्पविरामांनी विभागून, { } या वक्र-कंसांत लिहिले जातात.

उदा.: A = {२, ४, ६, ८, १०}

2

नियम पद्धत (Rule / Set-builder Method)

संचातील घटकांचा सामान्य गुणधर्म वापरून लिहिले जाते.

उदा.: A = { x | x = २n, n ∈ N, १ ≤ n ≤ ५ }

उदाहरणाने स्पष्टता

सोडवलेले उदाहरण १
"SCIENCE" या शब्दातील अक्षरांचा संच B दोन्ही पद्धतीने लिहा.
  • SCIENCE मधील अक्षरे : S, C, I, E, N, C, E.
  • संचातील घटक परस्पर भिन्न असतात; म्हणून C आणि E चे पुनरावर्तन वगळतो.
  • यादी पद्धत : B = {S, C, I, E, N}
  • नियम पद्धत : B = { x | x हे "SCIENCE" या शब्दातील अक्षर आहे }
सोडवलेले उदाहरण २
A = {१, ४, ९, १६, २५, ३६, ४९, ६४, ८१, १००} हा संच नियम पद्धतीत लिहा.
  • संचातील प्रत्येक घटक एका नैसर्गिक संख्येच्या वर्गासारखा आहे : $1=1^2,\ 4=2^2,\ \ldots,\ 100=10^2$.
  • म्हणून घटकाचे रूप : $x = n^2$, जिथे $n \in N$ आणि $1 \le n \le 10$.
  • नियम पद्धत : $A = \{ x \mid x = n^2,\ n \in N,\ n \le 10 \}$.
सावधान
नियम पद्धतीत वापरलेला "|" (किंवा कधीकधी ":") हा "असा की" असे वाचला जातो. उदा. { x | x सम संख्या } म्हणजे "x असा की x सम संख्या आहे".
सरावसंच १.१ · संपूर्ण उत्तरे

सरावसंच १.१ — पूर्ण उकल

प्रश्न १उत्तर पहा

खालील संच यादी पद्धतीने लिहा :
(i) सम नैसर्गिक संख्यांचा संच   (ii) १ ते ५० मधील सम मूळ संख्यांचा संच   (iii) ऋण पूर्णांकांचा संच   (iv) सरगमातील सात मूळ सुरांचा संच

उत्तर
  • (i) $A = \{2, 4, 6, 8, \ldots\}$ — असीमित संच
  • (ii) २ ही एकमेव सम मूळ संख्या आहे; म्हणून $B = \{2\}$
  • (iii) $C = \{-1, -2, -3, \ldots\}$
  • (iv) $D = \{$सा, रे, ग, म, प, ध, नि$\}$
प्रश्न २उत्तर पहा

पुढील चिन्हसंकेत वाक्यांत लिहा :
(i) $\tfrac{4}{3} \in Q$   (ii) $-2 \notin N$   (iii) $P = \{p \mid p \text{ ही विषम संख्या आहे}\}$

उत्तर
  • (i) "$\tfrac{4}{3}$ हा संच Q चा घटक आहे."
  • (ii) "−२ हा संच N चा घटक नाही."
  • (iii) "P हा अशा सर्व p चा संच आहे, की p ही विषम संख्या आहे."
प्रश्न ३उत्तर पहा

कोणत्याही दोन संचांचे उदाहरण यादी पद्धत व नियम पद्धत दोन्हींनी लिहा.

नमुना उत्तर
  • (i) A = "१० पेक्षा लहान सम नैसर्गिक संख्या" — यादी : $A = \{2, 4, 6, 8\}$; नियम : $A = \{x \mid x = 2n,\ n \in N,\ n < 5\}$.
  • (ii) B = "SCIENCE शब्दातील अक्षरे" — यादी : $B = \{S, C, I, E, N\}$; नियम : $B = \{x \mid x \text{ हे SCIENCE मधील अक्षर आहे}\}$.
प्रश्न ४उत्तर पहा

खालील संच यादी पद्धतीने लिहा :
(i) भारतीय सौर वर्षातील सर्व महिने (ii) COMPLEMENT शब्दातील अक्षरे (iii) मानवी ज्ञानेंद्रिये (iv) १ ते २० मधील मूळ संख्या (v) पृथ्वीवरील खंडांची नावे

उत्तर
  • (i) A = {चैत्र, वैशाख, ज्येष्ठ, आषाढ, श्रावण, भाद्रपद, आश्विन, कार्तिक, मार्गशीर्ष, पौष, माघ, फाल्गुन}
  • (ii) X = {C, O, M, P, L, E, N, T} (पुनरावर्तित अक्षरे एकदाच)
  • (iii) Y = {नाक, कान, डोळे, जीभ, त्वचा}
  • (iv) Z = {२, ३, ५, ७, ११, १३, १७, १९}
  • (v) E = {आशिया, आफ्रिका, युरोप, ऑस्ट्रेलिया, अंटार्क्टिका, दक्षिण अमेरिका, उत्तर अमेरिका}
प्रश्न ५उत्तर पहा

खालील संच नियम पद्धतीने लिहा :
(i) A = {१, ४, ९, १६, २५, ३६, ४९, ६४, ८१, १००}   (ii) B = {६, १२, १८, २४, ३०, ३६, ४२, ४८}   (iii) C = {S, M, I, L, E}   (iv) D = {रविवार, ..., शनिवार}   (v) X = {a, e, t}

उत्तर
  • (i) $A = \{x \mid x = n^2,\ n \in N,\ n \le 10\}$
  • (ii) $B = \{x \mid x = 6n,\ n \in N,\ n \le 8\}$
  • (iii) $C = \{y \mid y \text{ हे SMILE शब्दातील अक्षर आहे}\}$
  • (iv) $D = \{z \mid z \text{ आठवड्यातील एक वार आहे}\}$
  • (v) $X = \{y \mid y \text{ हे "eat" शब्दातील अक्षर आहे}\}$
घटक १.३

संचाचे प्रकार

∅

रिक्त संच (Empty / Null Set)

घटक नसलेला संच. दर्शविला जातो $\{\,\}$ किंवा $\varnothing$ ने.

उदा.: ऋण नैसर्गिक संख्यांचा संच = $\{\,\}$.

1

एकल संच (Singleton Set)

फक्त एक घटक असलेला संच.

उदा.: सम मूळ संख्यांचा संच = {२}.

=

समान संच (Equal Sets)

दोन संचांचे सर्व घटक एकसारखे असल्यास ते समान असतात. लिहिले जाते $A = B$.

⏺

सीमित संच (Finite)

ज्या संचातील घटक मोजता येतील, तो सीमित संच.

उदा.: इयत्ता ९वी च्या विद्यार्थ्यांचा संच.

∞

असीमित संच (Infinite)

घटक मोजता येत नाहीत. उदा.: N, W, I, Q, R.

n(A)

संचाचा घनतांक

संचातील घटकांची संख्या $n(A)$ ने दाखवतात. उदा. $A=\{2,4,6\}$ ⇒ $n(A) = 3$.

समान संच कसे ओळखाल?

  • दोन्ही संचांत हुबेहूब तेच घटक असले पाहिजेत — कमी नाही, जास्त नाही.
  • घटकांचा क्रम महत्त्वाचा नाही.
  • घटकांची पुनरावर्तन गृहीत धरत नाहीत.
सोडवलेले उदाहरण ३
A = सम मूळ संख्या; B = {x | 7x − 1 = 13}. हे संच समान आहेत का?
  • A : २ हीच एकमेव सम मूळ संख्या असल्याने $A = \{2\}$.
  • B : $7x - 1 = 13 \;\Rightarrow\; 7x = 14 \;\Rightarrow\; x = 2$. म्हणून $B = \{2\}$.
  • दोन्ही संचात एकच घटक "२" आहे; म्हणून $A = B$.
सोडवलेले उदाहरण ४
खालील संच रिक्त आहेत का?
(i) A = {a | a ही ० पेक्षा लहान नैसर्गिक संख्या}
(ii) B = {x | $x^2 = 0$}
(iii) C = {x | $5x - 2 = 0,\ x \in N$}
  • (i) नैसर्गिक संख्या १ पासून सुरू होतात; ० पेक्षा लहान नैसर्गिक संख्या नाही. म्हणून $A = \{\,\}$ — रिक्त संच.
  • (ii) $x^2 = 0 \Rightarrow x = 0$. म्हणून $B = \{0\}$. यात एक घटक आहे म्हणून रिक्त नाही.
  • (iii) $5x - 2 = 0 \Rightarrow x = \tfrac{2}{5}$, जी नैसर्गिक संख्या नाही. म्हणून $C = \{\,\}$ — रिक्त संच.

घटक १.४

उपसंच (Subset) व विश्वसंच (Universal Set)

व्याख्या — उपसंच
जर A या संचातील प्रत्येक घटक B या संचात असेल, तर A हा B चा उपसंच आहे असे म्हणतात. हे लिहिले जाते : $A \subseteq B$.
प्रत्येक संच स्वतःचा उपसंच असतो : $A \subseteq A$. रिक्त संच हा प्रत्येक संचाचा उपसंच असतो : $\varnothing \subseteq A$.

योग्य उपसंच (Proper Subset)

जर $A \subseteq B$ आणि $A \ne B$ असेल, तर A हा B चा योग्य उपसंच आहे; लिहितात $A \subsetneq B$.

व्याख्या — विश्वसंच
ज्या संदर्भात आपण अभ्यास करत असतो त्या सर्व संबंधित घटकांचा संग्रह म्हणजे विश्वसंच. हा सामान्यतः $U$ या अक्षराने दर्शविला जातो. आपण अभ्यासत असलेले सर्व संच $U$ चे उपसंच असतात.

संचाची पूरक (Complement)

व्याख्या
A हा संच विश्वसंच U चा उपसंच असेल, तर U मधील पण A मध्ये नसलेल्या सर्व घटकांचा संच म्हणजे A ची पूरक; दर्शवली जाते $A'$ किंवा $A^c$.
म्हणजेच $A' = \{ x \mid x \in U,\ x \notin A \}$.

पूरकेचे महत्त्वाचे गुणधर्म

  • $(A')' = A$   (पूरकेची पूरक मूळ संच असतो)
  • $U' = \varnothing$   आणि   $\varnothing' = U$
  • $A \cup A' = U$   आणि   $A \cap A' = \varnothing$
सोडवलेले उदाहरण ६
$U = \{1, 2, 3, 7, 8, 9, 10, 11, 12\}$, $P = \{1, 3, 7, 10\}$. P' काढा आणि $(P')' = P$ ही पडताळणी करा.
  • $P'$ साठी U मधील पण P मध्ये नसलेले घटक निवडा : $P' = \{2, 8, 9, 11, 12\}$.
  • आता $(P')'$ साठी U मधील पण $P'$ मध्ये नसलेले घटक : $\{1, 3, 7, 10\}$.
  • $(P')' = \{1, 3, 7, 10\} = P$. पडताळणी झाली.

घटक १.६

संचावरील क्रिया — संघ व छेद

∪

संघ (Union) — $A \cup B$

A किंवा B (किंवा दोघांत) येणारे सर्व घटक.

$A \cup B = \{ x \mid x \in A \text{ किंवा } x \in B \}$

∩

छेद (Intersection) — $A \cap B$

A आणि B या दोघांतही येणारे सामायिक घटक.

$A \cap B = \{ x \mid x \in A \text{ आणि } x \in B \}$

⊘

विभक्त संच (Disjoint)

$A \cap B = \varnothing$ असल्यास A आणि B विभक्त संच आहेत.

संघ व छेदाचे गुणधर्म

  • $A \cup B = B \cup A$   (क्रमविनिमेय / commutative)
  • $A \cap B = B \cap A$
  • $A \cup \varnothing = A$,   $A \cap \varnothing = \varnothing$
  • $A \cup A = A$,   $A \cap A = A$
  • $A \subseteq B \Rightarrow A \cup B = B$   आणि   $A \cap B = A$
  • De Morgan चे नियम :   $(A \cup B)' = A' \cap B'$   ,   $(A \cap B)' = A' \cup B'$
सोडवलेले उदाहरण ७
$U = \{1, 3, 5, 8, 9, 10, 11, 12, 13, 15\}$, $A = \{1, 11, 13\}$, $B = \{8, 5, 10, 11, 15\}$. खालील संच काढा व De Morgan चे नियम पडताळा.
  • $A' = U - A = \{3, 5, 8, 9, 10, 12, 15\}$.
  • $B' = U - B = \{1, 3, 9, 12, 13\}$.
  • $A \cap B = \{11\}$    ⇒    $(A \cap B)' = \{1, 3, 5, 8, 9, 10, 12, 13, 15\}$.
  • $A \cup B = \{1, 5, 8, 10, 11, 13, 15\}$ ⇒ $(A \cup B)' = \{3, 9, 12\}$.
  • $A' \cup B' = \{1, 3, 5, 8, 9, 10, 12, 13, 15\} = (A \cap B)'$ ✅
  • $A' \cap B' = \{3, 9, 12\} = (A \cup B)'$ ✅ — De Morgan पडताळला.

घटक १.७

घटक-संख्येचे सूत्र : $n(A \cup B) = n(A) + n(B) - n(A \cap B)$

दोन संचांच्या संघातील घटकांची संख्या काढण्यासाठी हे सूत्र अत्यंत उपयुक्त आहे. $n(A) + n(B)$ केल्यास, $A \cap B$ मधील घटक दोनदा मोजले जातात, म्हणून त्यांना एकदा वजा केले जाते.

मूळ सूत्र
$\boxed{\,n(A \cup B) = n(A) + n(B) - n(A \cap B)\,}$
येथून पुढील रूपे काढता येतात :
• $n(A \cap B) = n(A) + n(B) - n(A \cup B)$
• $n(\text{फक्त } A) = n(A) - n(A \cap B)$
• $n(\text{दोघांपैकी कोणीही नाही}) = n(U) - n(A \cup B)$
सोडवलेले उदाहरण ८
$n(A) = 15,\ n(A \cup B) = 29,\ n(A \cap B) = 7$. $n(B) = ?$
  • सूत्र वापरा : $n(A \cup B) = n(A) + n(B) - n(A \cap B)$.
  • $29 = 15 + n(B) - 7$.
  • $29 - 15 + 7 = n(B)$.
  • $\boxed{n(B) = 21}$.
सोडवलेले उदाहरण ९ — शब्द-समस्या
एका वसतिगृहात १२५ विद्यार्थी आहेत. त्यांपैकी ८० चहा पितात, ६० कॉफी पितात, २० दोन्हीही पितात. (अ) चहा किंवा कॉफी न पिणारे विद्यार्थी किती? (ब) फक्त चहा? (क) फक्त कॉफी?
  • $n(U) = 125,\ n(T) = 80,\ n(C) = 60,\ n(T \cap C) = 20$.
  • $n(T \cup C) = 80 + 60 - 20 = 120$ विद्यार्थी चहा किंवा कॉफी (किंवा दोन्ही) पितात.
  • (अ) चहा किंवा कॉफी न पिणारे = $n(U) - n(T \cup C) = 125 - 120 = \boxed{5}$.
  • (ब) फक्त चहा = $n(T) - n(T \cap C) = 80 - 20 = \boxed{60}$.
  • (क) फक्त कॉफी = $n(C) - n(T \cap C) = 60 - 20 = \boxed{40}$.

सरावसंच १.४ — पूर्ण उकल

प्रश्न १उत्तर पहा

$n(A) = 15,\ n(A \cup B) = 29,\ n(A \cap B) = 7$, तर $n(B) = ?$

उकल
  • $n(A \cup B) = n(A) + n(B) - n(A \cap B)$.
  • $29 = 15 + n(B) - 7$.
  • $n(B) = 29 - 8 = 21$. उत्तर : $n(B) = 21$.
प्रश्न २उत्तर पहा

एका वसतिगृहात १२५ विद्यार्थी आहेत; ८० चहा पितात, ६० कॉफी पितात, २० दोन्ही पितात. चहा किंवा कॉफी न पिणारे विद्यार्थी किती?

उकल
  • $n(U) = 125,\ n(T) = 80,\ n(C) = 60,\ n(T \cap C) = 20$.
  • $n(T \cup C) = n(T) + n(C) - n(T \cap C) = 80 + 60 - 20 = 120$.
  • चहा किंवा कॉफी न पिणारे = $n(U) - n(T \cup C) = 125 - 120 = 5$.
  • उत्तर : ५ विद्यार्थी चहा किंवा कॉफी पीत नाहीत.
प्रश्न ३उत्तर पहा

एका स्पर्धा परीक्षेत इंग्रजी विषयात ५० व गणितात ६० विद्यार्थी उत्तीर्ण झाले. ४० विद्यार्थी दोन्ही विषयात उत्तीर्ण आहेत. कोणीही दोन्हींत अनुत्तीर्ण नाही. किमान एका विषयात उत्तीर्ण किती?

उकल
  • $n(E) = 50,\ n(M) = 60,\ n(E \cap M) = 40$.
  • एकही विद्यार्थी दोन्हीत अनुत्तीर्ण नसल्याने एकूण = $n(E \cup M)$.
  • $n(E \cup M) = 50 + 60 - 40 = 70$.
  • उत्तर : ७० विद्यार्थी किमान एका विषयात उत्तीर्ण आहेत.
प्रश्न ४उत्तर पहा

इयत्ता ९ च्या २२० विद्यार्थ्यांचा सर्वे — १३० चा छंद रॉक क्लाइंबिंग, १८० चा छंद स्काय वॉचिंग, ११० चे दोन्ही छंद आहेत. (i) कोणताही छंद नसलेले किती? (ii) फक्त रॉक क्लाइंबिंग? (iii) फक्त स्काय वॉचिंग?

उकल
  • $n(U) = 220,\ n(R) = 130,\ n(S) = 180,\ n(R \cap S) = 110$.
  • $n(R \cup S) = 130 + 180 - 110 = 200$.
  • (i) कोणताही छंद नसलेले = $220 - 200 = \boxed{20}$.
  • (ii) फक्त रॉक क्लाइंबिंग = $n(R) - n(R \cap S) = 130 - 110 = \boxed{20}$.
  • (iii) फक्त स्काय वॉचिंग = $n(S) - n(R \cap S) = 180 - 110 = \boxed{70}$.
प्रश्न ५उत्तर पहा

दिलेल्या व्हेन आकृतीवरून पुढील संच लिहा. $A = \{x, y, z, m, n\}$, $B = \{p, q, r, m, n\}$, $U = \{x, y, z, m, n, p, q, r, s, t\}$.
(i) A   (ii) B   (iii) $A \cup B$   (iv) U   (v) $A'$   (vi) $B'$   (vii) $(A \cup B)'$

उत्तर
  • (i) $A = \{x, y, z, m, n\}$
  • (ii) $B = \{p, q, r, m, n\}$
  • (iii) $A \cup B = \{x, y, z, m, n, p, q, r\}$
  • (iv) $U = \{x, y, z, m, n, p, q, r, s, t\}$
  • (v) $A' = \{p, q, r, s, t\}$
  • (vi) $B' = \{x, y, z, s, t\}$
  • (vii) $(A \cup B)' = \{s, t\}$

प्रश्न १ — योग्य पर्याय निवडा (MCQ)

१ (i)उत्तर पहा

$M = \{1, 3, 5\},\ N = \{2, 4, 6\}$, तर $M \cap N = ?$

  • $\{1, 2, 3, 4, 5, 6\}$
  • $\{1, 3, 5\}$
  • $\varnothing$
  • $\{2, 4, 6\}$
उत्तर

(C) $\varnothing$ — M आणि N यांत एकही सामायिक घटक नाही.

१ (ii)उत्तर पहा

$P = \{x \mid x$ ही विषम नैसर्गिक संख्या, $1 < x \le 5\}$. यादी पद्धत?

  • $\{1, 3, 5\}$
  • $\{1, 2, 3, 4, 5\}$
  • $\{1, 3\}$
  • $\{3, 5\}$
उत्तर

(D) $\{3, 5\}$ — १ हा घटक नाही ($1 < x$); ३ आणि ५ विषम व ≤ ५.

१ (iii)उत्तर पहा

$P = \{1, 2, \ldots, 10\}$. P कोणत्या प्रकारचा संच आहे?

  • रिक्त
  • असीमित
  • सीमित
  • यांपैकी एकही नाही
उत्तर

(C) सीमित — १० घटक मोजता येतात.

१ (iv)उत्तर पहा

$M \cup N = \{1, 2, 3, 4, 5, 6\},\ M = \{1, 2, 4\}$, तर N = ?

  • $\{1, 2, 3\}$
  • $\{3, 4, 5, 6\}$
  • $\{2, 5, 6\}$
  • $\{4, 5, 6\}$
उत्तर

(B) $\{3, 4, 5, 6\}$ — N मध्ये $M \cup N$ मधील पण M मध्ये नसलेले घटक असले पाहिजेत व ४ हा सामायिक असू शकतो.

१ (v)उत्तर पहा

$P \subseteq M$ असेल, तर $P \cap (P \cup M) = ?$

  • P
  • M
  • $P \cup M$
  • $P' \cap M$
उत्तर व संकेत
  • $P \subseteq M \Rightarrow P \cup M = M$.
  • म्हणून $P \cap (P \cup M) = P \cap M = P$ (कारण $P \subseteq M$).
  • (A) P.
१ (vi)उत्तर पहा

खालीलपैकी कोणता संच रिक्त आहे?

  • समांतर रेषांच्या छेदबिंदूंचा संच
  • सम मूळ संख्यांचा संच
  • ३० पेक्षा कमी दिवस असलेला इंग्रजी कॅलेंडर महिना
  • $P = \{x \mid x \in I,\ -1 < x < 1\}$
उत्तर

(A) समांतर रेषा कधीही छेदत नाहीत; म्हणून त्यांच्या छेदबिंदूंचा संच रिक्त आहे.

प्रश्न २ — आणखी MCQ

२ (i)उत्तर पहा

खालीलपैकी कोणता संग्रह "संच" आहे?

  • इंद्रधनुष्याचे रंग
  • शाळेतील उंच झाडे
  • गावातील श्रीमंत लोक
  • पुस्तकातील सोपी उदाहरणे
उत्तर

(A) — इंद्रधनुष्याचे रंग निश्चित आहेत. इतर पर्यायांत "उंच", "श्रीमंत", "सोपी" हे शब्द व्यक्तिनिष्ठ आहेत.

२ (ii)उत्तर पहा

$N \cap W = ?$

  • $\{1, 2, 3, \ldots\}$
  • $\{0, 1, 2, 3, \ldots\}$
  • $\{0\}$
  • $\{\,\}$
उत्तर

(A) — N व W मधील सामायिक घटक १, २, ३, … आहेत.

२ (iii)उत्तर पहा

$P = \{x \mid x$ ही विषम नैसर्गिक संख्या, $1 < x < 5\}$. यादी पद्धत?

  • $\{1, 3, 5\}$
  • $\{1, 2, 3, 4, 5\}$
  • $\{1, 3\}$
  • $\{3, 5\}$
उत्तर

संदर्भग्रंथानुसार पर्याय (B) $\{1, 2, 3, 4, 5\}$. (टीप : प्रश्नात "विषम" शब्द असून $1 < x < 5$ या मर्यादांत फक्त ३ आहे; पाठ्यपुस्तकानुसार दिलेल्या उत्तरकुंजेत B स्वीकारलेले आहे.)

२ (iv)उत्तर पहा

$T = \{1, 2, 3, 4, 5\},\ M = \{3, 4, 7, 8\}$. $T \cup M = ?$

  • $\{1, 2, 3, 4, 5, 7\}$
  • $\{1, 2, 3, 7, 8\}$
  • $\{1, 2, 3, 4, 5, 7, 8\}$
  • $\{3, 4\}$
उत्तर

(C) $\{1, 2, 3, 4, 5, 7, 8\}$.

प्रश्न ३ — शब्द-समस्या (इंग्रजी / फ्रेंच)

३उत्तर पहा

एका गटात १०० व्यक्ती आहेत. त्यांपैकी ७२ इंग्रजी बोलतात, ४३ फ्रेंच बोलतात, प्रत्येकजण किमान एक भाषा बोलतो. किती जण फक्त इंग्रजी, फक्त फ्रेंच आणि दोन्ही बोलतात?

उकल
  • $n(U) = n(E \cup F) = 100$ (प्रत्येकजण किमान एक भाषा बोलतो).
  • $n(E) = 72,\ n(F) = 43$.
  • $n(E \cup F) = n(E) + n(F) - n(E \cap F)$.
  • $100 = 72 + 43 - n(E \cap F)$ ⇒ $n(E \cap F) = 115 - 100 = 15$.
  • दोन्ही भाषा बोलणारे = १५.
  • फक्त इंग्रजी = $72 - 15 = \boxed{57}$.
  • फक्त फ्रेंच = $43 - 15 = \boxed{28}$.

प्रश्न ४ — पार्थ व प्रद्न्या यांची वृक्षारोपण

४उत्तर पहा

पार्थने ७० व प्रद्न्याने ९० झाडे लावली. त्यांपैकी २५ झाडे दोघांनी मिळून लावली. एकूण किती झाडे पार्थ किंवा प्रद्न्याने लावली?

उकल
  • $n(P) = 70,\ n(Q) = 90,\ n(P \cap Q) = 25$.
  • $n(P \cup Q) = 70 + 90 - 25 = 135$.
  • उत्तर : १३५ झाडे.

प्रश्न ५ — $n(A \cap B)$ काढा

५उत्तर पहा

$n(A) = 20,\ n(B) = 28,\ n(A \cup B) = 36$. $n(A \cap B) = ?$

उकल
  • $36 = 20 + 28 - n(A \cap B)$.
  • $n(A \cap B) = 48 - 36 = 12$. उत्तर : १२.

प्रश्न ६ — कुत्रा / मांजर पाळणारे विद्यार्थी

६उत्तर पहा

वर्गात २८ विद्यार्थी आहेत. ८ कुत्रा, ६ मांजर पाळतात; १० विद्यार्थ्यांच्या घरी कुत्रा व मांजर दोन्ही आहेत. कोणीही पाळीव प्राणी नसलेले विद्यार्थी किती?
(टीप : पाठ्यपुस्तकातील व्हेन आकृतीनुसार "फक्त कुत्रा" = ८, "फक्त मांजर" = ६, "दोन्ही" = १०.)

उकल
  • व्हेन आकृतीतून : $n(D \cup C) = 8 + 10 + 6 = 24$.
  • कोणीही पाळीव प्राणी नसलेले = $n(U) - n(D \cup C) = 28 - 24 = 4$.
  • उत्तर : ४ विद्यार्थी.

प्रश्न ७ — संघ व्हेन आकृतीने दाखवा

७उत्तर पहा

(i) A = {३, ४, ५, ७}, B = {१, ४, ८}   (ii) P = {a, b, c, e, f}, Q = {l, m, n, e, b}   (iii) X = ८० ते १०० मधील मूळ संख्या, Y = ९० ते १०० मधील विषम संख्या.

उत्तर
  • (i) $A \cap B = \{4\}$, $A \cup B = \{1, 3, 4, 5, 7, 8\}$. व्हेन आकृतीत मध्ये ४, A च्या भागात ३, ५, ७ व B च्या भागात १, ८.
  • (ii) $P \cap Q = \{e, b\}$, $P \cup Q = \{a, b, c, e, f, l, m, n\}$.
  • (iii) $X = \{83, 89, 97\}$, $Y = \{91, 93, 95, 97, 99\}$, $X \cap Y = \{97\}$.

प्रश्न ८ — चौकोनांचे संच

८उत्तर पहा

X = सर्व चौकोन, Y = सर्व समभुज चौकोन, S = सर्व चौरस, T = सर्व समांतरभुज चौकोन, V = सर्व आयत. उपसंच संबंध लिहा.

उत्तर
  • सर्व आकार चौकोन आहेत : $Y \subseteq X,\ S \subseteq X,\ T \subseteq X,\ V \subseteq X$.
  • प्रत्येक चौरस हा समभुज, समांतरभुज व आयत असतो : $S \subseteq Y,\ S \subseteq T,\ S \subseteq V$.
  • प्रत्येक समभुज व प्रत्येक आयत समांतरभुज असतो : $Y \subseteq T,\ V \subseteq T$.

प्रश्न ९ — $M \cup \varnothing$ व $M \cap \varnothing$

९उत्तर पहा

M कोणताही संच असेल तर $M \cup \varnothing$ आणि $M \cap \varnothing$ लिहा.

उत्तर
  • $M \cup \varnothing = M$ — रिक्त संचातून घटक मिळत नाहीत.
  • $M \cap \varnothing = \varnothing$ — सामायिक घटकच नाहीत.

प्रश्न १० — व्हेन आकृतीतून संच लिहा

१०उत्तर पहा

दिलेल्या व्हेन आकृतीतून U, A, B, $A \cup B$, $A \cap B$ लिहा. (पाठ्यपुस्तकाप्रमाणे.)

उत्तर
  • $U = \{1, 2, 3, 4, 5, 7, 8, 9, 10, 11, 13\}$
  • $A = \{1, 2, 3, 5, 7\}$
  • $B = \{1, 5, 8, 9, 10\}$
  • $A \cup B = \{1, 2, 3, 5, 7, 8, 9, 10\}$
  • $A \cap B = \{1, 5\}$

प्रश्न ११ — सूत्र वापरून $n(A \cup B)$

११उत्तर पहा

$n(A) = 7,\ n(B) = 13,\ n(A \cap B) = 4$. $n(A \cup B) = ?$

उकल
  • $n(A \cup B) = n(A) + n(B) - n(A \cap B) = 7 + 13 - 4 = 16$.
  • उत्तर : $n(A \cup B) = 16$.
