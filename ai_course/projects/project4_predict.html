प्रकल्प ४: गुण अंदाज (Marks Predictor)

Azone Academy • रचना: Appaji Patil • अंदाजे वेळ: ४० मिनिटे

उद्दिष्ट

‘रोज किती तास अभ्यास’ या एका वैशिष्ट्यावरून परीक्षेतील गुणांचा अंदाज लावणारे ML मॉडेल बनवणे.

गणित — Linear Regression

आपण y = m · x + b या सरळ रेषेला डेटात बसवू. ‘चांगली’ रेषा म्हणजे प्रत्यक्ष व अंदाजित गुणांमधील त्रुटीचा वर्ग कमी असलेली.

m = ( n·Σxy − Σx·Σy ) / ( n·Σx² − (Σx)² )
b = ( Σy − m·Σx ) / n

संज्ञा

xइनपुट (अभ्यासाचे तास)
yआउटपुट (गुण)
m (slope)1 तास वाढल्यास गुण किती वाढतात
b (intercept)0 तास अभ्यासात अंदाजे गुण
R²मॉडेल किती ‘बसले’ — 1 = परिपूर्ण

मूल्यमापन (Evaluation)

  • MAE — सरासरी पूर्ण त्रुटी (mean absolute error).
  • RMSE — त्रुटींच्या वर्गांची सरासरीचे वर्गमूळ.
  • R² Score — मॉडेलने किती ‘variance’ स्पष्ट केले.
