प्रकल्प २: मराठी भावना विश्लेषक

Azone Academy • रचना: Appaji Patil • अंदाजे वेळ: ३० मिनिटे

उद्दिष्ट

दिलेले मराठी वाक्य सकारात्मक, नकारात्मक की तटस्थ हे आपोआप ठरवणारे साधन.

मूळ कल्पना (Idea)

सकारात्मक व नकारात्मक शब्दांचा एक शब्दकोश (lexicon) बनवू. वाक्यातील प्रत्येक शब्द त्या यादीत असेल तर गुण ± करत राहू. शेवटचा एकूण गुण भावना ठरवेल.

का? ही पद्धत सोपी आणि शिकायला उत्तम आहे. अधिक प्रगत मॉडेल्स हीच कल्पना मोठ्या डेटा + ML ने करतात.

शब्दकोश

positive = {
    "छान": 2, "मस्त": 2, "उत्तम": 3, "सुंदर": 2,
    "आवडले": 2, "आनंद": 2, "खूप": 1, "जिंकले": 2,
}
negative = {
    "वाईट": 2, "खराब": 2, "कंटाळवाणे": 2, "रडले": 2,
    "नापास": 3, "दुःख": 3, "त्रास": 2, "हरले": 2,
}
intensifiers = {"खूप": 2, "अति": 2}
negators     = {"नाही", "नको"}

सिंटॅक्स विश्लेषण

Dict {shabd: weight}शब्दाला किती वजन (intensity) द्यायचे.
Set { ... }फक्त शब्द आहे का — हे जलद तपासायला.

स्कोअर कसा मोजायचा?

  1. वाक्याचे tokens करा (split + lower).
  2. प्रत्येक शब्द — positive असेल तर +weight, negative असेल तर -weight.
  3. आधीचा शब्द ‘नाही’ असेल तर भावना उलटी होते.
  4. ‘खूप’/‘अति’ नंतर येणाऱ्या शब्दाचे वजन दुप्पट करा.
  5. एकूण score > 0 → सकारात्मक, < 0 → नकारात्मक, = 0 → तटस्थ.
