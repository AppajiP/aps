उद्दिष्ट

एक चॅटबॉट तयार करणे जो मराठीत विचारलेले काही प्रश्न ओळखून उत्तर देऊ शकेल. उदा. ‘तुझं नाव काय?’, ‘वेळ काय?’, ‘AI म्हणजे काय?’.

डिझाइन (कसा बनवायचा?)

  1. प्रत्येक प्रश्नासाठी काही कीवर्ड्स ठरवू.
  2. एक function लिहू: इनपुटमध्ये कोणते कीवर्ड्स आहेत ते तपासेल.
  3. योग्य कीवर्ड सापडल्यास तयार उत्तर परत करेल; नसेल तर "समजलं नाही".
  4. एक while लूप वापरून संवाद चालू ठेवू.

सिंटॅक्स विश्लेषण

{(a, b, c): "उत्तर"}Key म्हणून tuple — एकाच उत्तरासाठी अनेक कीवर्ड्स.
tuple( ... ) मध्ये बंदिस्त, बदलता न येणारी रचना.

पाऊल २ — उत्तर शोधणारे function

def uttar(text):
    t = text.lower()
    for words, ans in rules.items():
        if any(w in t for w in words):
            return ans
    return "माफ करा, हे मला समजले नाही. परत विचाराल का?"

सिंटॅक्स विश्लेषण

rules.items()Dict मधील (key, value) जोड्या एक-एक करून देते.
any(...)कोणतीही एक अट True असेल तर True.
for w in wordsTuple मधील प्रत्येक कीवर्ड तपासते.
returnउत्तर सापडले की पुढे जाण्याची गरज नाही — लगेच परत.
