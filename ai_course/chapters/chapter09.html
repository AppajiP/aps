१. जैविक न्यूरॉन आणि कृत्रिम न्यूरॉन

आपल्या मेंदूत सुमारे ८६ अब्ज न्यूरॉन्स आहेत. प्रत्येक न्यूरॉन इतर अनेकांकडून सिग्नल घेतो, त्यांची बेरीज करतो, आणि एका मर्यादेपेक्षा जास्त असेल तर पुढे ‘फायर’ (Fire) करतो. हीच कल्पना संगणकात उतरवली — त्यालाच कृत्रिम न्यूरॉन म्हणतात.

जैविककृत्रिम
Dendrite (इनपुट)Inputs x1, x2, ...
Synapse strengthWeights w1, w2, ...
Cell body — बेरीजz = Σ wi·xi + b
Axon — outputy = f(z) (activation)

२. परसेप्ट्रॉन

सर्वात साधे कृत्रिम न्यूरॉन. इनपुटला weights ने गुणून, bias मिळवून, मर्यादेच्या वर असेल तर 1, नाहीतर 0 देते. 

z = w1*x1 + w2*x2 + b
output = 1 if z >= 0 else 0
शिकणे = योग्य w1, w2, b शोधणे. प्रत्येक चुकीनंतर weights किंचित बदलून बरोबर उत्तराकडे जातात.

३. Layers: Input → Hidden → Output

एका न्यूरॉनने फार कठीण काम होत नाही, म्हणून अनेक न्यूरॉन्स ‘थर’ (layer) म्हणून जोडतात.

  • Input layer: कच्चा डेटा (पिक्सेल, गुण इ.)
  • Hidden layers: छुपे थर — pattern शिकतात. एकाहून जास्त असतील तर Deep Learning.
  • Output layer: शेवटचे उत्तर (वर्ग किंवा संख्या).

४. Activation Functions

नावसूत्रउपयोग
Step0 / 1परसेप्ट्रॉन
Sigmoid1/(1+e-z)संभाव्यता (0–1)
ReLUmax(0, z)आधुनिक Deep Learning
Softmaxmulti-classअनेक वर्ग वर्गीकरण
