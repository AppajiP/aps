२. व्हेरिएबल्स (Variables) व डेटा प्रकार

व्हेरिएबल म्हणजे माहितीसाठी ठेवलेले ‘नाव’ — एक डबा.

naav   = "आर्या"        # str — मजकूर
vay    = 14              # int — पूर्णांक
unchi  = 5.4             # float — दशांश
ahe_vidyarthi = True     # bool — खरे/खोटे

सिंटॅक्स विश्लेषण

घटकस्पष्टीकरण
=Assignment — उजवीकडची किंमत डाव्या व्हेरिएबलमध्ये ठेवते. तुलना नाही!
"..." / '...'String (मजकूर) दर्शवण्यासाठी अवतरण.
#Comment — पुढील मजकूर Python चालवत नाही.
type(naav)व्हेरिएबलचा डेटा प्रकार कोणता आहे ते सांगते.
नाव ठेवण्याचे नियम फक्त अक्षरे, अंक, अंडरस्कोर; पहिले अक्षर अंक नको. Python के case-sensitive आहे — Naav आणि naav वेगळे आहेत.

३. इनपुट व आउटपुट

naav = input("तुमचे नाव: ")
print("नमस्कार,", naav, "!")
घटकस्पष्टीकरण
input("...")वापरकर्त्याकडून मजकूर मागते आणि string परत करते.
print(a, b)स्क्रीनवर अनेक मूल्ये (स्पेसने जोडून) छापते.
int(x)String / float ला पूर्णांक बनवते (typecasting).
लक्ष द्या: input() नेहमी string देते. वय / गुणांसारखी संख्या हवी असल्यास int(input(...)) वापरा.

४. अटी (Conditions) — if / elif / else

gun = 72

if gun >= 75:
    print("उत्तम!")
elif gun >= 35:
    print("उत्तीर्ण")
else:
    print("पुन्हा प्रयत्न करा")
घटकस्पष्टीकरण
ifअट खरी असेल तर ब्लॉक चालतो.
elifआधीच्या अटी खोट्या असतील व ही खरी असेल तर.
elseवरील सगळ्या अटी खोट्या असतील तर.
Indentation४ स्पेस — Python मध्ये ब्लॉक ओळखण्याचा हाच मार्ग!
>= , <= , == , !=तुलना ऑपरेटर्स — boolean (True/False) देतात.

५. पुनरावृत्ती (Loops)

for लूप

for i in range(1, 6):
    print("नमस्कार", i)

range(1, 6) = 1, 2, 3, 4, 5 (6 वगळून). त्यामुळे ‘नमस्कार 1’ ते ‘नमस्कार 5’ छापले जाते.

while लूप

n = 1
while n <= 3:
    print(n)
    n = n + 1
घटकस्पष्टीकरण
range(a, b, step)a पासून b पर्यंत (b सोडून), प्रत्येक वेळी step ने वाढ.
while अट:अट खरी असेपर्यंत ब्लॉक पुन्हा चालतो.
break / continueलूप थांबवणे / पुढची फेरी सुरू करणे.

६. फंक्शन्स (Functions)

def beraj(a, b):
    """दोन संख्यांची बेरीज परत करते."""
    return a + b

print(beraj(3, 4))   # 7
घटकस्पष्टीकरण
def naav(...):नवीन function तयार करायचे keyword.
Parameters (a, b)Function ला दिले जाणारे इनपुट.
"""..."""Docstring — function काय करते याचे वर्णन.
returnउत्तर परत पाठवते. नसेल तर None.

७. List, Tuple, Dict, Set

yadi = [10, 20, 30, 40]          # List - बदलता येते
joda = (10, 20)                  # Tuple - बदलता येत नाही
kosh = {"naav":"राम", "vay":15}  # Dict - key:value
sangha = {1, 2, 3, 3, 2}         # Set - duplicates काढते

print(yadi[0])         # 10
print(kosh["naav"])    # राम
print(len(sangha))     # 3
yadi.append(50)        # शेवटी जोडा
संरचनाउपयोगउदा.
Listअनेक मूल्ये, क्रमाने, बदलता येतात.[1,2,3]
Tupleस्थिर मूल्ये (नंतर बदलणे शक्य नाही).(x, y)
DictKey-value रचना — माहितीचा "टेबल".{"a":1}
Setअद्वितीय (unique) मूल्ये.{1,2}
