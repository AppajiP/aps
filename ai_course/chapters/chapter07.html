१. Machine Learning (ML) म्हणजे काय?

“संगणकाला उदाहरणांवरून शिकवणे” — हेच ML. आपण नियम न लिहिता, फक्त उदाहरणे (data + correct answers) देतो; संगणक स्वतः नियम शोधतो.

उदाहरण: ‘कोणत्या ईमेल स्पॅम आहेत?’ हे ओळखायला आपण १००० स्पॅम + १००० सामान्य ईमेल देतो. ML मॉडेल त्यांचा अभ्यास करून नवीन ईमेलसाठीसुद्धा अंदाज देऊ शकते.

३. ML प्रकल्पाचे सहा टप्पे

  1. Problem Definition: काय शिकायचे? (वर्गीकरण/अंदाज?)
  2. Data Collection: डेटा गोळा करा.
  3. Preprocessing: स्वच्छ करा, missing भरा, scale करा.
  4. Train / Test Split: साधारण ८० % शिकवायला, २० % तपासायला.
  5. Model Training: Algorithm ने pattern शिकवा.
  6. Evaluation + Deployment: Accuracy तपासा, मग वापरा.

४. हँड्स-ऑन लॅब: पहिले मिनी-ML मॉडेल

आपण ‘अभ्यासाचे तास’ → ‘परीक्षा पास/नापास’ हे शिकू. येथे एक सोपा थ्रेशोल्ड शोधणारा (rule-finder) ML बनवू.
