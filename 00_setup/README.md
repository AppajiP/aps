## १. पायथन म्हणजे काय? (What is Python?)

**पायथन** ही एक **उच्च स्तरीय (high-level)** आणि **सोपी प्रोग्रामिंग भाषा** आहे. ती **गुइडो व्हॅन रॉसम (Guido van Rossum)** यांनी १९९१ मध्ये तयार केली.

### पायथन का शिकावी?

| कारण | स्पष्टीकरण |
|---|---|
| **सोपे सिंटॅक्स** | इंग्रजीसारखे वाचता येते — `print("नमस्कार")` |
| **विनामूल्य** | पूर्णपणे मोफत व open-source |
| **अनेक उपयोग** | वेबसाइट, AI, डेटा सायन्स, गेम्स, ऑटोमेशन |
| **रोजगाराच्या संधी** | जगातील सर्वात मागणी असलेल्या भाषांपैकी एक |

---

## २. पायथन स्थापना (Installation)

### विंडोज (Windows) साठी:

1. https://www.python.org/downloads/ ही वेबसाइट उघडा
2. **"Download Python 3.x.x"** या बटणावर क्लिक करा
3. download झालेली `.exe` फाइल उघडा
4. **"Add Python to PATH"** हा चेकबॉक्स ☑️ नक्की चालू ठेवा (खूप महत्वाचे!)
5. **"Install Now"** वर क्लिक करा
6. install पूर्ण झाल्यावर "Close" दाबा

### स्थापना तपासणे (Verify Installation):

`Command Prompt` (cmd) उघडा आणि खालील आज्ञा (command) टाइप करा:

```bash
python --version
```

जर असे काही दिसले — `Python 3.12.0` — तर अभिनंदन! पायथन यशस्वीरीत्या install झाले आहे. 🎉

## ३. IDE / एडिटर निवडणे

**IDE** म्हणजे **Integrated Development Environment** — जिथे आपण कोड लिहितो, चालवतो आणि चुका शोधतो.

| IDE / Editor | विशेषता | शिफारस |
|---|---|---|
| **IDLE** | पायथनसोबत install होतो | नवशिक्यांसाठी ✅ |
| **VS Code** | मोफत, ताकदवान, extensions | सर्वात लोकप्रिय ✅✅ |
| **PyCharm** | प्रोफेशनल, मोठ्या प्रोजेक्ट्ससाठी | प्रगत वापरकर्ते |
| **Jupyter Notebook** | डेटा सायन्ससाठी | विशेष कामासाठी |
| **Online: Replit** | install न करता वापरता येतो | शाळेच्या संगणकासाठी |

`lab_first_program.py` ही फाइल पाहा आणि चालवा.

### कसे चालवायचे?

## 📝 शब्दकोश (Glossary)

| शब्द (Term) | अर्थ (Meaning) |
|---|---|
| **Python** | प्रोग्रामिंग भाषा |
| **Install** | संगणकावर सॉफ्टवेअर बसवणे |
| **PATH** | सिस्टीमला सॉफ्टवेअर कुठे आहे ते सांगणारा मार्ग |
| **Command Prompt / Terminal** | आज्ञा टाइप करण्याचे काळे विंडो |
| **IDE** | कोड लिहायचे व चालवायचे ठिकाण |
| **Script** | `.py` extension असलेली पायथन फाइल |
| **Run / Execute** | प्रोग्राम चालवणे |

---

## ✅ स्वाध्याय

1. आपल्या संगणकावर पायथन install करा.
2. Command Prompt मध्ये `python --version` टाइप करून version तपासा.
3. `lab_first_program.py` चालवून बघा.
4. VS Code डाउनलोड करून install करा.
