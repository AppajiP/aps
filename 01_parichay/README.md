# प्रकरण ०१ — पायथनचा परिचय (Introduction to Python)

## 🎯 या प्रकरणात आपण काय शिकणार?

- `print()` फंक्शनचा उपयोग
- टीप (Comments) — एक ओळ व अनेक ओळींच्या

- `print()` मधील विशेष पर्याय — `sep`, `end`

## १. `print()` फंक्शन

### अर्थ व उपयोग

`print()` हे पायथनमधील एक **built-in function** आहे. याचे काम **स्क्रीनवर मजकूर (text) किंवा माहिती दाखवणे**.

### सिंटॅक्स (Syntax)

```python
print(value1, value2, ..., sep=' ', end='\n')
```

| भाग | अर्थ |
|---|---|
| `print` | फंक्शनचे नाव |
| `( )` | फंक्शन कॉल करण्यासाठी कंस |
| `value1, value2` | दाखवायच्या गोष्टी (अक्षरे, संख्या इ.) |
| `sep` | दोन गोष्टींमधील विभाजक (separator) — डीफॉल्ट म्हणजे जागा |
| `end` | शेवटी काय छापावे — डीफॉल्ट म्हणजे नवीन ओळ `\n` |

### सोपी उदाहरणे

```python
print("नमस्कार")              # नमस्कार
print("राम", "श्याम")         # राम श्याम
print("क", "ख", "ग", sep="-") # क-ख-ग
print("मराठी", end=" भाषा\n") # मराठी भाषा
```

## २. टीप (Comments)

**टीप (comment)** म्हणजे कोडमध्ये लिहिलेली अशी ओळ जी पायथन **चालवत नाही**. ती फक्त माणसांना समजावी म्हणून लिहितात.

### एक ओळीची टीप — `#`

```python
# ही एक टीप आहे
print("हा कोड चालेल")  # ही पण टीप आहे
```

### अनेक ओळींची टीप — `""" """`

```python
"""
ही एक मोठी टीप आहे.
अनेक ओळींची माहिती लिहिता येते.
"""
```

---

## ३. विशेष अक्षरे (Escape Characters)

| अक्षर | अर्थ |
|---|---|
| `\n` | नवीन ओळ (new line) |
| `\t` | टॅब (tab) — मोठी जागा |
| `\\` | backslash स्वतः छापणे |
| `\"` | string मध्ये double quote छापणे |
| `\'` | string मध्ये single quote छापणे |

### उदाहरण

```python
print("राम\nश्याम")       # दोन वेगवेगळ्या ओळींवर
print("नाव:\tगणेश")        # tab ने जागा
print("ती म्हणाली, \"हो\"")  # आत quotes छापणे
```

## 📝 शब्दकोश (Glossary)

| शब्द | अर्थ |
|---|---|
| **Function** | विशिष्ट काम करणारा कोडचा गट |
| **Built-in** | पायथनमध्ये आधीच तयार असलेले |
| **String** | अक्षरांचा समूह (अवतरण चिन्हांत) |
| **Argument** | फंक्शनला दिलेली माहिती |
| **Parameter** | फंक्शनने स्वीकारलेली माहितीची जागा |
| **Output** | प्रोग्रामचे उत्तर / निकाल |
| **Escape Sequence** | `\` ने सुरू होणारे विशेष अक्षर |

## ✅ स्वाध्याय

1. आपले नाव, वय व गाव वेगवेगळ्या तीन ओळींवर छापा.
2. `print()` वापरून आपल्या वर्गाचे वेळापत्रक छापा (tab व newline वापरून).
3. एका `print()` मध्ये पाच नावे जोडून (`-` ने) छापा.
4. खालील output येईल असा प्रोग्राम लिहा:
   ```
   नमस्कार,	मी पायथन शिकत आहे.
   "पायथन" मला आवडते!
   ```
